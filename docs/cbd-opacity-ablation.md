# CBD 子地图 7 不透明度对照

将 26 个高斯的不透明度乘以 0.75 后，CBD 73 号的 565 个远深度标签全部保留，RMSE 降低
15.7 mm。同一视角全部共同覆盖的 LiDAR 标签上，RMSE 增加 0.7 mm。65 号的 RGB 指标变化
很小，11 个图像像素跌破覆盖阈值。这一结果验证了远层不透明度对局部误差的作用，整幅图的
深度结果使本轮对照止于离线诊断。

## 对照口径

使用[整包回放](cbd-noetic-stratified-additions.md)的分层补点封口模型和最终留出相机。65 号联合
块 4 和块 7，73 号联合块 0 和块 7。两路块 7 均为资产 `17`，manifest SHA-256 为
`bdb6b9d1fa4c8c27544cbd8efad083aaf3beeb7b628502ab9750a1a445b8f60e`。

从[上一轮射线归因](cbd-73-depth-attribution.md)中选取 32 条高误差射线上实际参与合成的块 7
远层高斯，冻结 26 个去重索引。两组仅用这批索引的 `sigmoid(logit)` 原值或乘以 0.75 再转回
`logit`。渲染复用相机、子地图位姿、位置、尺度、颜色及邻块资产。实际概率比在
`[0.74999988, 0.75000010]` 内。

73 号沿用 565 个参考深度至少 20 m、在 2 px 和 4 px 下均获重复参考层支持且近层未重复的标签，
以及其中的 32 条高误差与 32 条稳定射线。深度使用相机坐标系的 z，误差取渲染减参考。两视角
以 alpha 至少 0.05 的共同覆盖作为配对深度分母，并统计原有覆盖中的丢失。PSNR 和 SSIM 使用
各自同一幅 324,038 像素的有效图像掩码，保留空洞像素。

## 射线权重

32 条高误差射线中，19 条实际受这批高斯贡献。块 7 远层平均归一化权重从 36.09% 降至
33.32%，该层对平均深度偏差的贡献减少 0.0898 m。块 0 远层平均权重由 13.56% 增至 14.01%，
其偏差贡献增加 0.0138 m。选中高斯的不透明度下降后，后续贡献通过透射率和归一化变化参与
重新分配。各块与各层合计使高误差组平均深度移近 0.0775 m，RMSE 由 2.326 m 降至 2.253 m。
稳定组仅 1 条射线直接使用被调整的高斯，平均移近 0.035 mm。64 条射线全部保留覆盖。

## 复验与产物

本机使用 RTX 4060 Laptop、PyTorch 2.3.0+cu121、gsplat 1.5.3 和 NumPy 1.26.4。两次 GPU
运行都逐元素复现原始两视角的 RGB、alpha、深度，第二次也逐元素复现调整侧浮点数组与射线贡献。
两次 CPU 核验从相同的归档样本复算评分和 128 条射线记录，逐项校验 450 个有序合成项。射线
alpha 和期望深度相对渲染结果的最大复算误差分别为 8.08e−8 和 1.72e−5 m。

原始证据放在工作区的 `validation/cbd-73-opacity-20261128/`。`protocol.json` 绑定索引、相机、
标签、射线和输入内容收据，`variants.npz` 保存调整侧图像及两侧射线贡献，`render-report.json`
记录浮点资产和实际不透明度，`analysis.json` 保存配对统计。`study-files.sha256` 核对脚本、报告、
日志和图像。Matplotlib 绘图脚本为 `plot_depth_change.py`。

以下命令在原登记路径使用上述 CUDA Python 环境。跨机复查时需带上位于工作区阶段目录中的脚本
及[整包封口和评分归档](cbd-noetic-stratified-additions.md)、[射线归因归档](cbd-73-depth-attribution.md)
和其中引用的 Retail 射线辅助脚本。收据记录绝对路径。在新路径重复实验时，先按这两个阶段的
复现说明在实际路径准备输入与收据，再在新建的阶段目录运行并省略 `--verify`。逐元素复验以
同一登记路径和本次原生扩展为准。

```bash
cd /path/to/livo-atlas_ws
export PYTHONDONTWRITEBYTECODE=1 PYTHONNOUSERSITE=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 OMP_THREAD_LIMIT=1
CUDA_VISIBLE_DEVICES=0 python validation/cbd-73-opacity-20261128/render_opacity.py --verify
CUDA_VISIBLE_DEVICES='' python validation/cbd-73-opacity-20261128/analyze_opacity.py --verify
cd validation/cbd-73-opacity-20261128
sha256sum -c study-files.sha256
```
