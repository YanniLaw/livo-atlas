# P1-01 基础类型约定

这些类型是新核心接口的基础；当前旧前端尚未迁移到它们。命名空间为 `livo_atlas`，头文件目录为 `include/livo_atlas/core/`，只使用C++17标准库与已有Eigen依赖。

## 帧标识

`FrameId`采用64位无符号整数，0为 `kInvalidFrameId`，有效值从1开始。当前只约定单次运行内处理帧的标识；分配策略与重置生命周期留给其对应任务。本项不定义全局跨会话唯一性，也不添加未来地图/关键帧ID体系。

## 时间

`Timestamp`采用有符号64位整数纳秒，有效范围为0到int64最大值，0是合法时间。时间属于输入传感器的时间轴，不自动解释为Unix时间；缺失时间不能用0代替。时间偏移、持续时间和ROS发布墙钟不应混用为观测时间。

转换规则：

- 整数秒与纳秒分量应通过整数运算转换；纳秒分量必须小于10亿，秒非负，最终结果不得溢出。
- 旧算法的double秒通过显式转换进入整数时间：拒绝非有限值、负值、越界值，舍入到最近纳秒；精确半纳秒时向较大值舍入。
- double秒不能保留大时间戳中的每一纳秒。从整数时间转成double秒再转回来，不保证逐纳秒相等。能获得整数sec/nsec时，优先走整数路径。
- 转换失败不得改写调用者已有输出。核心层不读取ROS消息，不应用相机/IMU时间偏移；未来适配层负责调用转换。

| 接口 | 输入及结果 |
|---|---|
| `TimestampFromSeconds(double, Timestamp*)` | 旧double秒按实际可表示值舍入，成功返回true |
| `TimestampFromSecondsAndNanoseconds(int64_t, uint32_t, Timestamp*)` | 秒与规范化纳秒分量精确组合，成功返回true |
| `kNanosecondsPerSecond` | 每秒10亿纳秒 |

两个函数都拒绝空输出指针；失败返回false。例：整数秒2、纳秒345678901得到2345678901；秒9223372036、纳秒854775807恰好得到int64最大值，再增加1纳秒即拒绝。double输入`1.0/1024.0`秒恰好为976562.5纳秒，舍入为976563。位姿验算示例：绕Z轴旋转π/2后平移(1,2,3)，B系点(1,0,0)应变为A系点(1,3,3)；可执行例子见 `tests/core_types_test.cc`。

当前使用简单类型别名，不具备编译期单位或ID隔离能力；调用处必须通过变量命名和接口约定维持语义，避免为了类型隔离提前引入通用模板框架。

## 刚体位姿

`Pose3d`复用 `Eigen::Isometry3d`，长度为米、角度为弧度。

- 数学记号 `T_A_B` 表示把B系点转换到A系：`p_A = T_A_B * p_B`。
- 组合：`T_A_C = T_A_B * T_B_C`；逆：`T_B_A = T_A_B.inverse()`。
- C++变量使用小写，例如 `t_odom_imu`、`t_imu_camera`；两者乘积得到 `t_odom_camera`。
- 新位姿必须显式初始化，例如使用 `Pose3d::Identity()`；Eigen默认构造不保证单位变换。
- 旋转必须满足正交且行列式为+1。该别名不自动验证输入矩阵；不可将含缩放、错标方向或未校验数据的矩阵直接当作有效刚体变换。

本项不制定文件四元数顺序、不创建序列化API、不隐式转换旧滤波状态。相关适配应在消费这些类型的具体任务中实现并验收。

## 验收边界

测试使用已知非平凡旋转和平移核对组合、逆与点变换，误差门限1e-12米；时间转换验证整数精度、舍入与拒绝路径。构建和测试记录见[P1-01](acceptance/P1-01.md)。本项测试不证明物理标定或完整SLAM正确性。
