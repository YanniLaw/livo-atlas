# CBD 73 号远深度归因

沿用[离线深度支持评分](gaussian-depth-support.md)中的 CBD 73 号视角。比较 flat 和分层补点
的已封口模型。两侧都选所属块 7、邻块 0，相机、物化位姿、子地图变换和每块训练谱系均一致。
重投影得到的 2、4 px 邻帧票数与已保存结果逐元素一致。

## 子地图交换

初始分母为参考深度至少 20 m、两种半径都获重复参考支持且近层未重复的 565 个共同联合标签。
两个原始联合组合均覆盖全部标签，只换所属块覆盖 559 个，只换邻块覆盖 563 个。下表固定在
四种组合共同覆盖的 557 个标签。深度误差取渲染减参考，正值表示更远。

| 所属块 7 / 邻块 0 | 平均有符号误差 (m) | RMSE (m) | 相对两块 flat 的净平方误差变化 (m²) |
| --- | ---: | ---: | ---: |
| flat / flat | +0.158 | 0.621 | 0 |
| 分层补点 / flat | +0.194 | 0.834 | +172.84 |
| flat / 分层补点 | +0.147 | 0.607 | −9.61 |
| 分层补点 / 分层补点 | +0.189 | 0.859 | +196.88 |

以两块 flat 为起点，只换所属块复现约 88% 的净增量。只换邻块时误差下降，组合交互项为
+33.65 m²。全 565 个标签上两个原始联合组合的净增量为 +198.82 m²。

在六种渲染都覆盖的 497 个标签上，单块净增量为 +168.55 m²，两个原始联合组合的净增量为
+152.90 m²。该分母上只换所属块增加 157.24 m²，只换邻块减少 9.53 m²，交互项为 +5.19 m²。
两个分母都指向所属块 7 的模型变化。

## 实际射线权重

在首次渲染前固定 32 条高误差射线和 32 条对照。高误差按原始联合平方误差增量排序，每 8×8 格
最多取一条。两侧原始深度误差均小于等于 0.25 m、两侧深度差小于等于 0.10 m 的像素用于对照。
对照的参考深度配对差中位数为 0.019 m，最大 0.554 m。所选高误差射线贡献了原 565 个
标签净增量的 68.6%，后续射线表描述这一局部样本。

两种单块与四种联合共六次渲染。四份原始 alpha 和深度逐元素复现。独立复算用 384 条射线记录和
1,337 项有序贡献验证 `权重 = 透射率 × alpha`。最大 alpha 误差为 8.58e−8，最大期望深度
误差为 1.73e−5 m。

对 32 条高误差射线，以下比较两块 flat 与两块分层补点。按 `max(0.20 m, 0.03 × z_ref)`
容差区分近层、匹配层和远层。各层权重先在每条射线归一化再取平均。偏差贡献是该层权重乘
深度残差的和，整条射线各项相加得到期望深度的改变。

| 子地图 / 深度层 | flat 平均权重 | 分层补点平均权重 | 对平均深度变化的贡献 (m) |
| --- | ---: | ---: | ---: |
| 所属块 7 / 近层 | 1.52% | 4.29% | −0.201 |
| 所属块 7 / 匹配层 | 70.81% | 40.51% | −0.003 |
| 所属块 7 / 远层 | 12.64% | 36.09% | +0.769 |
| 邻块 0 / 近层 | 0.24% | 2.89% | −0.025 |
| 邻块 0 / 匹配层 | 8.99% | 2.65% | −0.004 |
| 邻块 0 / 远层 | 5.79% | 13.56% | +0.163 |

整体平均移远 0.700 m，其中只换所属块移远 0.515 m，只换邻块移远 0.129 m。稳定组两块
都换后平均移远 0.014 m。所属块 7 的远层 +0.769 m 中，约 +0.656 m 来自该层合成权重增加，
+0.114 m 来自该层自身的加权深度变化。分解按两侧平均深度和平均权重对称计算，单侧缺层时
使用存在侧的层内深度作为共同值。

下一次单变量诊断可先检查不透明度对远层权重的影响，固定位置、尺度和颜色，并沿用相同分母。
本次权重变化由已训练资产的可见性和合成共同产生，足以定位待测试的输出机制。

## 复现与文件

本机归档在 `validation/cbd-73-depth-20261128/`，约 1 MiB。`protocol.json` 绑定冻结像素和输入，
`renders.npz` 保存目标像素的 alpha、深度和逐射线贡献，`analysis.json` 保存分层和交互结果。
`rays.png` 用红色标出高误差像素，蓝色标出对照。`study-files.sha256` 可核对记录。

以下命令在原归档路径使用已有 CUDA Python 环境与 gsplat 1.5.3。复验会重新渲染并比较浮点数组。
在新目录重复试验时，先按[CBD 整包对照](cbd-noetic-stratified-additions.md)和
[多帧评分](gaussian-depth-support.md)准备当前路径的输入与收据，再移除 `--verify` 运行。

```bash
cd /path/to/livo-atlas_ws
export PYTHONDONTWRITEBYTECODE=1 PYTHONNOUSERSITE=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python validation/cbd-73-depth-20261128/render_mix.py --verify
python validation/cbd-73-depth-20261128/analyze_mix.py --verify
```
