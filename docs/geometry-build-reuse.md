# 几何完整构建中的体素累计

按用户批准的下一步，用已有真实点云先建立离线基准，再减少新建几何子地图中的事务复制。
保持逐点输入顺序、体素统计公式、快照排序、异常处理与3块驻留预算。

## 方案与边界

当前公开 AddKeyframe 复制已有体素表，再更新副本并交换，确保任意错误不改变原 builder。
GeometryMapper::Build 自己创建局部 builder，完整块生成之前不对外发布；中途失败时，
整个局部 builder 都会销毁。这条路径不需要逐帧复制已经累计的体素表。

采用私有 AddKeyframeInPlace，完整保留输入检查和原来的逐点计算；只允许 GeometryMapper
在新建、未发布的 builder 上使用，失败即丢弃。公开 AddKeyframe 仍在副本上操作，成功
后才交换数据。输入头部先检查再复制，保留非法输入的拒绝顺序；私有入口也自行检查。
公开路径因此会重复一次轻量头部检查，避免把“调用前必须先检查”变成隐含前提。

新增一个 GeometryMapper 友元和两个私有方法，不增加公开接口、类数据成员、运行参数或
编译宏。GeometryMapper::Append 继续调用公开事务入口。不会复制两套逐点累计算法。

相比之下，直接修改所有更新路径会破坏错误回滚；对每个修改做回滚日志会引入复杂状态。
跨查询缓存和提高驻留容量属于其他问题，本轮不实施。

## 验收

离线基准只读已有 keyframes 数据集，将真实 body cloud 预先装入内存，使用已确认的最终
位姿，排除磁盘读取和 ROS 回放调度。覆盖所有13块完整子地图，分别记录公开事务入口的
累计、快照，以及 GeometryMapper 完整构建和其内快照。交替运行顺序，多轮报告，不根据
单次运行宣称端到端收益。修改前的安装库和基准可执行文件冻结到独立证据目录。

已有 geometry_failure_test 的分配钩子用于比较多帧完整构建与公开逐帧事务参考的分配次数，
用宽松的相对上限验证消除重复复制，不使用墙钟阈值作单元测试。比较所有几何字段，
补充跨多帧构建失败后的重试和已发布快照不变，以及公开入口分配失败的回滚。

收益明确后做 SDK 全套、Noetic/Humble 相关测试和 Retail_Street 完整回放，逐资产、数学
诊断、缓存计数和归档对照，继续记录 LIO/VIO 分位数和最大值。无稳定收益则保留原实现。
工作区证据目录：validation/geometry-build-20261126。

## 离线结果

同一份基准源分别链接冻结的修改前/后安装库，固定 CPU6、单线程运行，预热后每组交替
公开/完整构建顺序各7次。另做两组配对，并反转前后程序顺序。原始点云预加载、结果比较、
指纹写入和 mapper 元数据 Update 均不计入下表；两条路径的创建与释放范围不同，不把
mapper 与公开入口的绝对比值当作完整系统加速比。

| 13块构建的中位秒数 | 第1组前 / 后 | 第2组前 / 后 | 第3组前 / 后 |
| --- | --- | --- | --- |
| 公开事务参考 | 0.461 / 0.483 | 0.437 / 0.435 | 0.417 / 0.414 |
| GeometryMapper 完整构建 | 0.500 / 0.305 | 0.467 / 0.299 | 0.456 / 0.281 |
| 完整构建中位数下降 | 39.0% | 35.9% | 38.4% |

额外独立遍历测得 builder 副本构造与销毁合计约0.154～0.182秒，快照读取用于验证副本，
不计入副本计时。复制是明确的成本来源，但内存局部性和容器容量也会变化，不能把全部
耗时差都归为复制自身。公开事务参考同时作为运行波动的对照。

分配回归用例的完整构建从36925次分配降到6164次，约减少83.3%；公开逐帧参考为36921次。
这是16帧合成用例的分配请求数，不是实际地图的峰值内存降幅。回归不使用墙钟阈值。
公开入口逐个分配失败的回滚、后期非法点、多帧中途分配失败、重试和旧快照不变均通过。

真实172帧、13块的公开参考输出包含全部选项、来源、质心、协方差、法线和成员列表，
前后序列化 SHA256 相同，为
`66d32d6f31d3258a5e95a350b3358b01e559aece3a5d405e697665b009d675b0`。
Mapper 每一轮都逐字段与公开参考进行精确数值比较，没有容差；该比较将正负零视为相等，
未另外序列化 mapper 输出，因此不把这个 SHA256 描述为 mapper 输出的独立字节校验。
常规分配用例使用单点体素；可后续补充非零协方差和有法线的体素断言。真实点云基准已
覆盖对应字段：共169030个体素，其中135898个非零协方差、57136个有法线。
