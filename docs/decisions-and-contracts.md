# 待定决策与契约补充

本文区分既定方向和待实现细节。待定项须在对应任务开工前形成具体约定，不把设计建议当成已验证能力。

## 需逐项补齐的内容

| 内容 | 需要明确的问题 | 最迟完成点 |
|---|---|---|
| 环境与数据 | 主目标硬件、ROS/依赖版本、实际数据和标定；LIO/LIVO/LO 各模式支持范围 | P0-08 |
| 基线门限 | 轨迹差异、时延统计口径、峰值内存、允许掉帧、重复运行波动 | P0-04 |
| 兼容策略 | 旧 topic/TF/frame_id/参数/可执行文件/输出格式的保留和迁移办法 | P0-07 |
| 状态不确定度 | 切空间排列、左右扰动、协方差坐标和单位；无有效协方差时如何表示 | P1-03 |
| 高速 IMU 输出 | 现有传播定时器与融合状态快照的锁顺序、时间和关闭规则 | P1-13 |
| 同步异常 | 乱序、重复、缺帧、队列满、时间回退各自处理策略 | P1-10/11 |

| 跟踪质量 | 数量、残差、退化和持续时间如何驱动状态机 | P4-06 |
| 3DGS 目标 | 训练器固定版本、相机模型、输入格式、硬件及质量指标 | P2-10/12 |
| 深度语义 | Z/射线距离/逆深度、尺度、无效值、遮挡和置信度 | P5-02/03 |
| 在线训练 | 高斯修正、事件重放、背压、检查点与地图版本关联 | P5-10～13 |

## 决策记录方式

重要决策记录编号、任务、问题、可行选项、选定方案、依据、影响和状态。实现中发现新证据可以修订，但保留旧结论及修订原因。无需为普通局部实现引入审批流程；用户验收通过仍是任务完成的必要条件。

## 初始约定

- D001：前端拥有唯一可写滤波状态；后端第一版通过全局位姿与地图重建修正结果。
- D002：核心重构保持现有数学更新语义；时间发布等行为修正单独交付。
- D003：观测与估计分离，导出读取固定版本快照。
- D004：逐细分任务实施，用户本地验收后才通过。
- D005：P5 扩展分项验收，不以离线训练完成推断在线训练完成。

## 性能与质量报告要求

至少记录输入时长、播放倍率、是否包含启动初始化、处理帧数和丢帧、前端耗时统计、峰值内存、队列峰值与退出状态。轨迹比较记录时间关联、坐标对齐及真值来源。资源门限先按目标硬件和基线确定，禁止事后为让结果通过而无记录地修改。
