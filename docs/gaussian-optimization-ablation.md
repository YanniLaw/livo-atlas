# 高斯均值与尺度的单变量冻结试验

2026-11-27，继[种子追踪诊断](gaussian-seed-diagnostics.md)之后，在 Retail_Street 与
CBD_Building_01 的既有冻结前缀上，分别把高斯均值、尺度学习率设为零。两场景、两次重复中，
两种冻结均降低单块 SSIM、联合覆盖和联合 PSNR，并增大六次共同覆盖像素上的深度 L1/RMSE。
这轮不支持以完全冻结均值或尺度解决 replace25% 的质量问题；训练器和在线默认保持不变。

## 干预对象和固定条件

三种条件都使用 `seed_policy=coverage`、`coverage_sampling=replace`、
`coverage_uncovered_ratio=0.25`。每次只把一个原本为正的学习率改成零：

| 条件 | means | log_scales | color_logits | opacity_logits |
| --- | ---: | ---: | ---: | ---: |
| baseline | 0.0005 | 0.002 | 0.01 | 0.01 |
| means0 | 0 | 0.002 | 0.01 | 0.01 |
| scales0 | 0.0005 | 0 | 0.01 | 0.01 |

零学习率从每个高斯初始化开始，贯穿其所在子地图的全部训练，对所有高斯生效。
`means` 是子地图坐标中的 XYZ，不是 SLAM 相机或子地图位姿。`log_scales` 包括三个尺度轴，
冻结后始终为初始化的各向同性 0.03m；既禁止尺寸变化，也禁止学出各向异性。
四元数沿用原模型的固定值，其他两项参数正常更新。没有同时固定位置和尺度。

每观测最多初始化 1000 点，窗口 10，每块最多 10000 点，每调用 20 步；当前帧 10 步，
另外 10 步按既有顺序回看窗口中的旧帧，没有旧帧时继续使用当前帧。六次训练的观测、
角色划分、损失调度、最终位姿、原生空间邻居选择和其余配置相同。

| 场景 | 冻结帧 / train / heldout | 单块 / 联合查询 | 调用 / 步数（每次） | 累计初始化 / 最终驻留高斯（每次） |
| --- | ---: | ---: | ---: | ---: |
| Retail | 172 / 150 / 22 | 21 / 19 | 150 / 3000 | 150000 / 120000 |
| CBD | 97 / 85 / 12 | 12 / 10 | 85 / 1700 | 85000 / 77000 |

三条件各运行随机种子 0、1，共 12 次全新完整前缀训练，不复用旧模型。
这里的“完整”指冻结前缀内的全部训练观测，不能解释为每个 bag 的所有原始消息。
输入沿用已归档的 [Retail 参考](spatial-heldout-comparison.md) 与 [CBD 参考](cbd-building-sampling.md)，
本轮没有重新估计轨迹或重放 ROS。

改变均值或尺度会影响 alpha 预渲染，进而可能改变后续初始化种子。固定的是采样规则、比例、
输入和预算，不是每次调用的种子像素 ID。本轮测量的是固定选块和最终位姿条件下，
“优化加采样反馈”的总效应，不能解释为同一组高斯上纯粹的位置或尺寸贡献。

## 留出结果

表中为两次重复的描述性均值。每次先沿用已有指标聚合：RGB 误差按像素归并后转换为 PSNR，
SSIM 按完整有效的 11×11 窗口数归并，覆盖率以有效图像像素为分母；再对两次结果取均值。
没有先对查询的 dB 值求平均。alpha 覆盖阈值为 0.05。

| 场景 / 条件 | 单块 SSIM ↑ | 联合 SSIM ↑ | 联合 PSNR(dB) ↑ | 联合覆盖(%) ↑ | 共同深度 L1(m) ↓ | 共同深度 RMSE(m) ↓ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Retail / baseline | 0.22923 | 0.29063 | 12.0214 | 92.4956 | 0.23448 | 0.91807 |
| Retail / means0 | 0.15765 | 0.21826 | 11.2285 | 90.6686 | 0.24791 | 0.96656 |
| Retail / scales0 | 0.17255 | 0.22326 | 10.9124 | 90.1956 | 0.24256 | 0.93494 |
| CBD / baseline | 0.15994 | 0.15986 | 8.9916 | 71.5047 | 0.21507 | 0.91113 |
| CBD / means0 | 0.12183 | 0.12266 | 8.6364 | 68.1610 | 0.23832 | 1.00556 |
| CBD / scales0 | 0.11684 | 0.11506 | 8.3822 | 66.4938 | 0.24335 | 1.00120 |

深度表只使用每场景六次运行都覆盖的相同 LiDAR 参考像素：Retail 联合查询为
228371 / 254967（89.5688%），CBD 为 86717 / 136346（63.6007%）。
每次在这些像素上汇总绝对误差及平方误差，再计算 L1/RMSE。单块交集另为
Retail 219601 / 281620、CBD 92123 / 162748，完整值在 `audit.json`。
无共同像素时指标应为 null；不能将其写成零，也不能直接与此前其他交集上的深度值排序。
未覆盖区域不进入深度误差，必须连同覆盖率和交集比例解读；稀疏 LiDAR 参考不等同于稠密几何真值。

与同场景 baseline 相减：

| 场景 / 干预 | 单块 SSIM 差 | 联合覆盖差(百分点) | 联合 PSNR 差(dB) | 共同深度 L1 差(mm) |
| --- | ---: | ---: | ---: | ---: |
| Retail / means0 | -0.07158 | -1.8270 | -0.7929 | +13.43 |
| Retail / scales0 | -0.05668 | -2.3000 | -1.1090 | +8.08 |
| CBD / means0 | -0.03811 | -3.3437 | -0.3552 | +23.25 |
| CBD / scales0 | -0.04310 | -5.0109 | -0.6095 | +28.27 |

上述四项在每个配对重复中方向相同，不是仅由两次均值造成的符号变化。
这不表示所有单独查询都变差，也不构成显著性检验或跨场景泛化证明。
`optimization-ablation.png` 展示单块 SSIM、联合覆盖和共同深度 L1，误差线仅为两次的范围。

八组比较均生成误差、空洞、深度支持和联合增益面板。人工查看 seed0 的 Retail 查询 169、
CBD 查询 41：固定参数后仍呈稀疏斑点，部分区域的空洞增加，未恢复参考图中的细节。
这些视图由既有最差 RGB 误差规则选出，不能作为全场景随机样本或独立的机制证据。

目标数组在初始化后 120 步中完全不变，其他参数仍发生变化。
这些见证使用代表性开发子地图独立重训，不是完整评估模型的逐点归档，也不参与留出质量评分。

## 跨电脑复现

按场景保留同一参考 `gaussian`、`slam/keyframes` 和配置，三个条件各用 seed0、1：

```bash
python tools/3dgs_probe/evaluate_gaussian_sampling.py \
  --map-directory /data/reference/gaussian --keyframes /data/reference/slam/keyframes \
  --prepare-executable /sdk/bin/livo_atlas_prepare_3dgs_views \
  --selector-executable /sdk/bin/livo_atlas_select_gaussian_neighbor \
  --config /data/means0.yaml --seed-policy coverage --random-seed 0 \
  --output /data/means0-0
```

配置沿用对应场景已归档的 replace25% YAML，仅修改 `gaussian.worker.learning_rates.means`
或 `log_scales` 为 `0.0`。其他两项学习率保持原值；baseline 使用原学习率。
每次输出使用新目录，输入参考和拆分不变。配置同时保存在评估结果的 `config.yaml` 中。

```bash
python tools/3dgs_probe/compare_gaussian_sampling.py \
  --baseline /data/baseline-0 --candidate /data/means0-0 \
  --frozen-parameter means --output /data/comparison-means0-0
```

`--frozen-parameter means|log_scales` 只读取并验收已生成结果，不执行冻结或训练。
它要求指定项从正数变零，拒绝同时改两项、反向、非零候选或其他配置/类型差异，
并与比例、采样方式比较模式互斥。结果声明 `comparison_scope=learning_rates.<name>`
和两端数值；默认比较模式仍拒绝学习率变化。

工作区 `validation/gaussian-optimization-ablation-20261127/` 保存 `protocol.json`、
`implementation.json`、六份配置、12 套评估、8 套见证与比较、`execution.jsonl`、测试日志、
`audit_study.py` / `audit.json`、汇总及绘图脚本。训练源版本为 `11e2627`，训练器/模型/默认配置
相对上一阶段 `a05c4c9` 不变。比较器审查修复为 `f398438`，八组 `review-comparison-*` 重新验收，
报告均与原结果逐字节相同；`comparison-revalidation.json` 单独绑定这次只读比较器的指纹。
独立审计保持原训练源指纹约束，仅允许比较器使用上述重验指纹，并重新核对报告一致性。
独立审计应使用对应工具源和原生准备器/选块器重新运行。
比较诊断图的摘要尚未合入复用审计脚本；当前 48 张原比较面板已由独立检查及最终审查另行核对，

## 后续范围

本轮排除了“直接完全冻结可以改善当前预算下成绩”这条简单路径，未证明适度调整学习率也无效。
固定 XYZ 仍允许尺度、opacity 和混合权重改变渲染深度，不能把均值不动理解为深度不变。
若继续研究，可先以一个较小的正均值学习率做单变量试验；尺度和其他学习率保持 baseline，
沿用同一前缀、预算和共同深度验收。它仍是待验证假设，暂不并入在线默认。
梯度保护选点、正则或增密继续列为后续候选，不同时加入多种机制再归因。
两场景两次重复没有轨迹真值对照，也未验证在线 P95、长距离重访或其他平台。
