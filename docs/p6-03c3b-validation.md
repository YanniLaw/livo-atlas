## 交付与边界

新增独立 CLI `tools/3dgs_probe/render_gaussian_map.py` 和普通 Python 数值函数，完整 CPU
验证后才创建输出和初始化 CUDA。复用原有严格 map/state 读者和 gsplat rasterizer，
保持原 public inspector 返回语义；CPU 模块不依赖 Torch。没有修改 C++、ROS 共用入口、
IPC、训练调度或资产 schema，也没有新增 Pimpl、模型封装或可见性框架。

一次显式选择一至两块、至多 20,000 Gaussian、一个至多 1M 像素的保留训练相机。
CPU float64 相对变换同时旋转中心及各向异性形状，GPU float32 在单位 view matrix 下
联合光栅化。单块参考与联合顺序执行，查询来自第三块时该块也不会污染联合输入。
产物、错误行为、时间终点和指标定义见[使用说明](online-gaussian.md#最终快照联合渲染)。

## 测试及候选真实案例

- Python/真实 CUDA 141/141，root 工具 76/76；GPU 必须可用，无跳过或回退。
- 新增 31 项包含严格 CPU 快照/blocked-Torch 预检、完整 state 逐次释放、旧 capture/尾部、
  非交换旋转、协方差、q 与 -q、180°、大原点、输入所有权和预算。
- 真实 CUDA 单块对旧路径：RGB/alpha 绝对容差 1e-5，深度 1e-4m；两块深度 2/8 与 4/6
  交错，用四个真实单 Gaussian alpha 和独立 front-to-back 公式验证 RGB/alpha/ED。
  调换块输入顺序结果相同，反转深度产生颜色变化；所有推理张量无梯度。
- 手算 mask/零样本/完美 MSE 指标；32 内容块报告仍有界。CUDA OOM、缺预编译扩展、NPZ
  写入、报告写入和最后 rename 故障均非零且无成功标记；渲染期间来源变化也被拒绝。
  故障注入只在测试侧外部调用边界，保留真实文件、校验和渲染路径。
