# VIO 图像采样边界修复

2026-10-11 定位问题，2026-10-18 接续验证。该修复与数学/状态迁移分开提交。

## 原因与证据

默认前向 VIO 在 `updateState` 中按 `level + search_level` 采样图像。
入口的固定边界只考虑金字塔层数，没有覆盖额外的搜索层和梯度采样偏移。
因此进入视觉子图的点，在较粗层上仍可能越过图像范围。

只增加边界诊断、保持原计算的参考节点在第 361 帧记录：

```text
frame=361 point=92 level=3 search=2 scale=32
center=(480,384) margin=160 image=(640,512)
```

最后的采样坐标会达到 `(640,544)`，超出有效图像。
这与相同参考二进制重复运行约 36.5 秒后开始出现状态差异的区间相符。
诊断在实际读取之前退出，日志位于工作区
`validation/P1-01-noetic-20261011/vio_mean_fix/sampling-diagnostic/run/mapping.log`。

## 修复与直接回归

每个点在当前层检查完整的双线性插值与梯度采样范围，只跳过当前层不安全的测量。
有效细层仍可使用同一个点；有效粗层仍参与曝光更新。
每次迭代清零残差与雅可比，避免被排除的测量残留；没有有效测量时退出该层。
每帧清零信息矩阵，避免整帧没有有效测量时复用上一帧的协方差更新。

`tests/vio_sampling_test.cc` 直接调用真实 VIO 方法，四个用例覆盖：

- 不安全粗层不受图像相邻存储内容影响。
- 同一点的安全细层继续更新曝光。
- 安全粗层继续更新曝光。
- 全部测量无效时，状态和协方差不变。

测试给图像分配明确的前后填充区。相同图像仅改变填充值，就能在修复前观察到错误的姿态、位置和曝光变化；不依赖分配器偶然返回的字节。
修复前两个无效测量用例失败，两个有效测量用例通过；修复后四个均通过。
红/绿日志位于上述诊断目录的 `tests/red.log`、`tests/green.log`。
