# 高斯投影中心与空洞诊断

2026-11-27，继[均值学习率试验](gaussian-means-rate.md)，对 Retail 留出帧97和 CBD 留出帧9
运行有界诊断。训练后覆盖高于同一保留集合的初始参数对照；约98.6%–99.1%的最终空洞在该对照中
也未覆盖。多数最终空洞的4像素邻域没有投影中心，但约97%的空洞也没有当前查询的LiDAR深度标签。
这些是空间覆盖的观测关系，不能确定唯一成因，也不支持直接修改点数、训练器或在线默认。

## 固定对象与证据

每个查询使用seed0、1各一次，原率coverage/replace25%、1000点/观测、窗口10、10000点/块、
20步/调用不变。原生空间选择基于既有冻结参考模型，查询相机使用最终位姿；没有按新结果重选邻居。

| 查询 / 模式 | 子地图 | 每次调用 / 步数 | 全部实际初始化点 / 最终保留点 |
| --- | --- | ---: | ---: |
| Retail97 / single | 6 | 与joint共用同次训练 | 18000 / 10000 |
| Retail97 / joint | 5、6 | 27 / 540 | 27000 / 19000 |
| CBD9 / single | 0 | 11 / 220 | 11000 / 10000 |

共四次诊断、六个子地图训练、76调用1520步。两帧来自既有开发查询，不是盲测或全场景采样。
本轮重新训练这些有界子地图，没有重放bag或重估轨迹，也不要求CUDA训练与旧运行逐位相同。

离线 `CaptureModel` 只复制实际初始化参数，以及已有预渲染返回的覆盖掩码，不增加渲染或随机数调用。
掩码按little bit order压缩，缺预渲染用空数组区分；它们使独立审计能够重建每次自适应选点。
保存三类中心：全部实际初始化、最终保留点的初始化位置、同批保留点的训练后位置。
最后两者的origin逐点对应；初始参数对照使用同批点的原始位置、0.03m尺度、0.5 opacity及初始颜色。
它是静态对照，不是训练过程中某个真实时刻的整张地图，也不是独立于优化反馈的种子集合。

## 中心邻域与稀疏深度

将中心投影后按 `floor(u+0.5)`、`floor(v+0.5)` 归入像素格，使用整数偏移
`dx²+dy²<=r²` 的0/2/4像素圆形邻域。近画幅外的中心可以支持边界邻域，背面或z<=1e-6的中心不计。
这不是高斯椭圆足迹、表面可见性或连续投影距离；没有邻域中心不能推断绝对没有高斯贡献。

最终空洞中，训练后中心在相应邻域完全缺席的比例：

| 查询 / 模式 | r=0(%) | r=2(%) | r=4(%) |
| --- | ---: | ---: | ---: |
| Retail single | 100.000 | 99.933 | 96.617 |
| Retail joint | 100.000 | 99.930 | 96.544 |
| CBD single | 100.000 | 99.923 | 93.596 |

这种关系部分受alpha覆盖本身与高斯足迹约束，不能独立证明增加点数就会改善画质。
本轮尚未把全部未入选的有效源深度候选重投影，因此不能区分输入本身未覆盖与1000点抽样丢掉了已有支持。

只有带当前LiDAR标签的最终空洞，才比较邻域中心z与该目标像素参考深度，容差为max(0.05m,2%z)。
consistent优先；无consistent时分别为front-only、behind-only、同时front/behind的mixed，或没有中心的none。
每个目标像素独立检验深度，避免把某个中心像素的深度类别直接膨胀到另一表面。
front/behind只是深度关系，不等于已经证明遮挡或几何错误。
