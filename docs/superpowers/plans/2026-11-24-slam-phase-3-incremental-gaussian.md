# SLAM 在线 3DGS 增量通知实施计划

在共享 ROS 入口迁移最后一个完整快照消费者。单块预览和持久化子地图共用 `GaussianMapIndex` 的成员与位姿前沿。追加交付新帧的修正位姿，索引只更新本轮的成员和几何关系。训练与联合渲染需要完整位姿时取得同一前沿的只读快照。 [3.1 阶段设计](../specs/2026-11-24-slam-engineering-optimization-design.md#31-减少重复校验和历史复制)

## 1. 提交和索引

- [x] 在索引测试中对照增量与完整观察。覆盖跨块追加、无效修订回退、刚性修正后复用、修正版本后的尾帧追加和组内位姿变化后待重建。
- [x] 给 `OnlineSubmapDelta` 补充本次追加的修正位姿。`OnlineSubmapManager` 复用局部几何已经使用的尾部位姿计算。位姿提交继续携带完整的已提交版本。
- [x] `GaussianMapIndex::ObserveDelta` 按顺序验证最多两条成员修订。追加时保存单条位姿并更新受影响的条目，封存时更新成员状态。全量路径继续校验先前位姿前缀，优化提交比对当前位姿与实际训练及存盘资产的位姿。
- [x] `GaussianMapIndex` 在派发需要时创建只读位姿快照，同一前沿可复用。地图快照中的每块绑定使用同一帧数和位姿版本。保留 512 帧及已训练块的现有预算。

## 2. 调度和收尾

- [x] 用现有模拟 worker 运行实际 `LivoSystem` 的增量通知，验证优化后的追加和最终封存。保持旧 SDK 入口和两种训练模式的版本、资源及停止行为。
- [x] `OnlineGaussianMapper::ObserveDelta` 使用统一索引，回调只接纳新数据和更新待处理状态。任务派发保有独立的位姿和观测，结果继续按版本及成员前缀判断。优化提交保留资产重绑和重建调度。联合渲染的需求更新只读索引版本。
- [x] `Finalize` 冻结索引和系统均认可的最后位姿前沿。ROS1 和 ROS2 从同一个 `main` 把 3DGS 连接到现有增量回调。

## 3. 验收

- [x] 在相同的合成成员和驻留条件下统计普通追加中的全量位姿校验次数、遍历位姿数和成员校验次数。3DGS 现有 512 帧上限内取样，另核对实际派发及位姿提交使用快照。
- [x] 跑独立 SDK、Noetic 与 Humble 的相关测试。Noetic 用 RTX 4060 对照 Retail_Street 的单块短回放和持久化完整回放，核对前端和位姿归档、播放期预览、回环后的资产、联合渲染和最终封存。记录由异步派发导致的资产覆盖和时序差异，在当前分支本地提交。

## 追加测量

对照基线为 `3acce81`。每块有 16 个主关键帧，采样轮次同时处理上一块封存和下一块创建。单块与持久化模式的同步追加得到相同的校验计数。

| 已有关键帧 | 全量位姿校验（前 → 后） | 遍历位姿数（前 → 后） | 成员校验（前 → 后） |
| ---: | ---: | ---: | ---: |
| 32 | 3 → 0 | 66 → 0 | 2 → 2 |
| 128 | 3 → 0 | 258 → 0 | 2 → 2 |
| 256 | 3 → 0 | 514 → 0 | 2 → 2 |
| 496 | 3 → 0 | 994 → 0 | 2 → 2 |

零扫描覆盖同步追加及其观察回调。训练派发会取完整快照。联合渲染筛选候选时也可能捕获快照，随后因当前内容或调度条件暂缓派发。

## 回放与回归

- 独立 SDK 的 76 个 CTest 目标均通过。Noetic 与 Humble 各通过 12 个相关测试目标，两个共享入口均通过停钟状态下的模拟 worker 测试。增量路径覆盖连续观测合并到同一预览、优化提交后的追加、刚性修正与重建和最终封存。
- Noetic 配对回放使用逻辑 CPU 2、OpenMP 单线程、RTX 4060 Laptop GPU 和 1× 速度。10 秒单块回放两侧各有 98 次 LIO、97 次 VIO 和 5 个已接纳预览。增量版首个播放期预览在约 3.81 秒出现。
- 完整持久化回放两侧各有 1,352 次 LIO、1,351 次 VIO 和 2 条接纳回环。轨迹、ROS 前端载荷、516 份关键帧文件及 185 份成员记录一致。两次优化提交的帧数分别从 141 和 169 变为 142 和 170，共有的位姿前缀一致。按相同尾部规则还原到最终 172 帧后，位姿矩阵元素最大绝对差为 `1.71e-15`。
- 两次完整回放均将 13 个子地图封存到位姿版本 2，目录检查验证了所有资产和最终化报告。增量版收到 72 份双块联合预览，记录 10 次重绑和 19 次重建。基线对应为 56、6 和 17。这些次数随异步调度和训练覆盖变化。

回放工具使用 `--rate 1 --cpu-affinity 2 --image-queue-size 32 --loop-closure --semantic-output --stage-timing`。单块回放设 `--duration 10`。完整回放设 `--duration 136`，并开启 `--gaussian-persist-submaps --gaussian-finalize-on-shutdown --gaussian-joint-render --joint-render-policy spatial --gaussian-publish-preview`。worker 和工作目录的设置见 [在线 Gaussian 回放说明](../../online-gaussian.md#使用-ros1-bag-做成对检查)。

本机摘要 `incremental-gaussian-verification.json`、探针和日志保存在工作区的 `validation/slam-incremental-gaussian-20261124/`。
