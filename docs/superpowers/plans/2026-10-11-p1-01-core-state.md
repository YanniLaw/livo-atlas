# P1-01 数学与状态隔离 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把数学类型、SO(3) 运算和 19 维状态迁入仅依赖 Eigen 的核心头，同时保持 Noetic 算法行为与 P0 修复后基线一致。

**Architecture:** 新核心头位于 `include/livo_atlas/core`，使用 `livo_atlas` 命名空间。旧头通过类型别名、函数导入或薄包装继续提供已有名称；状态与数学运算只有一份实现。模板与小型状态运算保留为头文件实现，本阶段不增加插件接口或新运行线程。

**Tech Stack:** C++17、Eigen、Google Test、CMake；集成验证使用 ROS1 Noetic 和现有 PCL/OpenCV/Sophus/vikit。

**Spec:** [前端重构设计](../specs/2026-10-11-refactor-architecture-design.md)，本计划只实施其中 P1-01。

## Global Constraints

- 本次只修改 `livo-atlas` 包；`rpg_vikit` 保持原样。
- ROS1 验证平台为本机 Noetic；ROS2 目标为 Humble。后端优化与 3DGS 实现分别作为后续项目。
- 新增和实质修改的 C++ 代码采用 Google 风格。本轮保留工程现有 C++17 工具链。
- 保留 19 维误差状态排列：旋转 0–2、位置 3–5、逆曝光 6、速度 7–9、陀螺偏置 10–12、加速度偏置 13–15、重力 16–18。
- 保留右乘旋转增量、初始协方差和全部数学分支。整理命名与修改数值公式分开提交。
- `Exp`/`Log` 的阈值、重力模型、滤波更新、传感器时间及标定不变。
- 默认使用编译器基准指令集，避免强制 native 或 fast-math。构建采用 `nice -n 10`、`-j1`，与回放依次运行。
- 同机、同工具链的纯迁移要求轨迹和状态日志在原导出精度内一致；不一致时调查原因，不能通过轨迹对齐隐藏差异。

`rot_end`、`pos_end`、`vel_end`、`inv_expo_time`、`bias_g`、`bias_a`、`gravity`、`cov` 暂时保留原名称与字段顺序，属于已记录的兼容范围。PCL 点类型、`Pose6D`、`set_pose6d`、ROS 测量结构及算法源文件留待后续阶段。

## Task 1：数值类型与 SO(3) 运算

**Files:** 新增 `math_types.h`、`so3_math.h`、`tests/core/math_test.cc`、`test_main.cc`、`CMakeLists.txt`；修改两个 `include/utils` 兼容头。

**Interfaces:**

- 类型：`livo_atlas::Vector2f`、`Vector2d`、`Vector3d`、`Matrix3d`、`Vector3f`、`Matrix3f`，分别为同名 Eigen 类型的别名。
- `template <typename T> Eigen::Matrix<T, 3, 3> Exp(const Eigen::Matrix<T, 3, 1>&& angle)`。
- `template <typename T, typename Ts> Eigen::Matrix<T, 3, 3> Exp(const Eigen::Matrix<T, 3, 1>& angular_velocity, const Ts& dt)`。
- `template <typename T> Eigen::Matrix<T, 3, 3> Exp(const T& x, const T& y, const T& z)`。
- `template <typename T> Eigen::Matrix<T, 3, 1> Log(const Eigen::Matrix<T, 3, 3>& rotation)`。
- `template <typename T> Eigen::Matrix<T, 3, 1> RotationMatrixToEuler(const Eigen::Matrix<T, 3, 3>& rotation)`。
- 旧 `Exp`/`Log` 用 `using` 导入；旧 `RotMtoEuler` 只调用 `RotationMatrixToEuler`。旧 `MD/VD/MF/VF` 宏及 skew 系数宏保留在兼容头，核心不依赖它们。

- [ ] **Step 1：新增针对核心入口的失败用例与独立测试入口。**

`PreservesSmallAngleBranches` 的关键断言为：

```cpp
const Eigen::Vector3d angle(0.0, 0.0, 1e-6);
EXPECT_TRUE(Exp(0.0, 0.0, 1e-6).isIdentity(0.0));
EXPECT_FALSE(Exp(Eigen::Vector3d(angle)).isIdentity(0.0));
EXPECT_FALSE(Exp(Eigen::Vector3d::UnitZ().eval(), 1e-8).isIdentity(0.0));
```

分别测试 `double` 和 `float`。向量阈值两侧输入为 `0.5e-7` 和 `2e-7`，标量阈值两侧输入为 `0.5e-5` 和 `2e-5`；保留原 double 字面量比较，不把阈值改成按 T 舍入的常量。速度重载的判断对象是速度范数，而非乘上 `dt` 后的角度。
`RotatesAroundKnownAxis` 使用 0.25 弧度的 Z 轴旋转，期望矩阵系数为 `cos(0.25)`、`sin(0.25)`，覆盖三个重载；容差 double 为 `1e-12`、float 为 `1e-6`。
`PreservesLogBranches` 覆盖单位阵、0.0005 弧度与 0.25 弧度的 Z 轴旋转，小角度的 Z 输出为 `sin(0.0005)`，一般分支为 0.25。
`PreservesEulerSingularityConvention` 覆盖普通 Z 轴旋转和 Y 轴 π/2 旋转；奇异分支 yaw 为 0，pitch 为 π/2。

独立测试 CMake 最低版本为 3.10，启用 C++17，查找 Eigen3 和 GTest，链接 `Eigen3::Eigen` 与 `GTest::GTest`；共用 `test_main.cc` 提供 main，不重复链接 gtest_main。

## Task 2：共享状态与 Noetic 回归

**Files:** 新增 `state.h`、`tests/core/state_test.cc`、`tests/legacy_core_compatibility_test.cc`；修改 `common_lib.h`、两个测试构建入口及实施记录文档。

**Interfaces:**

- 接收 Task 1 的 Eigen 别名与 SO(3) 运算。
- `inline constexpr int kStateDimension = 19`；`inline constexpr double kInitialCovariance = 0.01`、`kGravityMetersPerSecondSquared = 9.81`。
- `using StateIncrement = Eigen::Matrix<double, kStateDimension, 1>`，`using StateCovariance = Eigen::Matrix<double, kStateDimension, kStateDimension>`。
- `struct State` 保留原字段类型与顺序；提供 `State()`、值语义复制/赋值、`State operator+(const StateIncrement&) const`、`State& operator+=(const StateIncrement&)`、`StateIncrement operator-(const State&) const`、`void ResetPose()`。
- 旧 `StatesGroup` 为 `livo_atlas::State` 别名；兼容成员 `void resetpose()` 只调用 `ResetPose()`；`DIM_STATE/INIT_COV/G_m_s2` 转发对应常量。

- [ ] **Step 1：新增状态失败用例和 Noetic 兼容用例。**

`InitializesStateAndCovariance`：单位旋转，五个向量为零，逆曝光为 1；协方差非对角为零，索引 0–5、7–9 的对角为 0.01，6、10–18 为 0.00001。
`PreservesNineteenStateIndices`：依次对每个索引施加 0.01 的单项增量，只有对应量变化；旋转使用独立 `Eigen::AngleAxisd` 作为期望。
`RightMultipliesRotation`：初值绕 X 轴 π/2，增量绕 Y 轴 0.25；期望 `R_x * R_y`，同时验证 `+` 和 `+=`。
`DifferenceRecoversIncrement`：增量各项为 `0.01 * (index + 1)`，初始旋转非单位阵；`updated - original` 在 `1e-12` 内等于输入增量。
`PreservesCovarianceAndCopiesValues`：协方差设为 `0.2 * I` 并设置 `(1, 5)`、`(5, 1)` 为 0.002；加法、复制和赋值保留全部矩阵；修改复制对象不改变原对象。
`ResetPosePreservesCalibrationAndCovariance`：初始位置 `(1, 2, 3)`、速度 `(4, 5, 6)`、逆曝光 1.5、陀螺偏置 `(0.01, 0.02, 0.03)`、加速度偏置 `(0.1, 0.2, 0.3)`、重力 `(0, 0, -9.81)`；重置只使旋转成为单位阵、位置和速度归零，其余量及协方差精确保留。

兼容测试必须包含旧头，并至少包含这些断言：

```cpp

static_assert(std::is_same<V3D, livo_atlas::Vector3d>::value);
static_assert(DIM_STATE == livo_atlas::kStateDimension);
```
