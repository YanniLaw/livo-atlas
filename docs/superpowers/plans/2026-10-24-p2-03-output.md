# P2-03 输出分离执行计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Frontend 输出普通快照，文件写入和 ROS1 发布各自独立。

**Architecture:** FrontendResult → OutputProcessor → ResultWriter / ros1::ResultPublisher；Mapper 只顺序编排。旧算法只采集诊断，不做 ROS 或文件 I/O。

**Tech Stack:** C++17、Eigen、PCL、OpenCV、现有 vikit 私有相机、Noetic、GTest、Python。

**Spec:** `docs/superpowers/specs/2026-10-24-p2-03-output-design.md`。

1. 两个实例间的着色/图像/COLMAP/PCD 计数不得共享；Task 2 用独立目录和输出编号验证。
2. 未初始化/空更新仍写先验，但不能多发布或写后验；Task 2/3 用真实 Frontend 初始化和 ROS 输出验证。
