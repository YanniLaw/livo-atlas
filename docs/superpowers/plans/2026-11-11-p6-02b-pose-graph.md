# P6-02b GTSAM Pose Graph Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan in the current session, unless the user selects another execution method. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 提供可选的普通 C++ GTSAM 位姿图，用模拟约束验证优化结果通过既有位姿版本和几何修正路径交付。

**Architecture:** `PoseGraph` 直接持有原始关键帧位姿和显式约束，调用时局部构造 GTSAM 图并批量求解。
调用者在 `ProcessNext` 返回后串行应用 `PoseUpdate`；本阶段不把模拟约束或独立优化线程接入生产 ROS 节点。

**Tech Stack:** C++17、GTSAM 4.2.2 验收基线、Eigen、GTest、CMake 3.16、Noetic、Humble。

**Spec:** [P6-02b 位姿图设计](../specs/2026-11-11-p6-02b-pose-graph-design.md)。状态：**已实施并完成阶段验收**，实际范围见[验证记录](../../p6-02b-validation.md)。
用户已选择 Task 0 的版本化刚体尾帧策略；旧调用与旧文件保留旧语义。

## 全局约束

- 只修改 `livo-atlas`；遵循 Google C++ 规范、函数定义之间空行、直接成员，不使用 Pimpl。
- `LIVO_ATLAS_WITH_GTSAM=OFF` 为默认；关闭时不得查找、链接或加载 GTSAM，ROS1/ROS2 保持同一 main。
- ROS、GTSAM 类型不进入普通公共数据接口；图与 `LivoSystem` 均只有一个串行所有者。
- 不引入真实闭环、map→odom TF、IMU 图因子、前端修正反馈、后台线程、GPU 或在线 3DGS。
- 初始噪声仅为实验权重：先验旋转/平移标准差 0.001 rad/0.001 m；里程计为 0.05 rad/0.1 m。
  显式回环各自提供正的旋转/平移标准差；所有标准差、变换和目标函数必须有限。
- GTSAM 4.2.2 验收构建采用与工程相同的系统 Eigen；记录 ABI、CPU 指令、构建选项与实际库摘要。
- 资源验证在本机串行 `nice -n 10`、`-j1`、`OMP_THREAD_LIMIT=1`；不启动 RViz。
- 原始 bag、历史回放和其他包只读；新构建、依赖和结果放在本阶段独立 `validation/P6-02b-20261111/`。

## 审阅重点

1. 非交换 SE(3) 和噪声顺序：错误的相对变换方向会产生看似有效但错误的图；Task 1 用旋转加平移测试。
2. 输入允许小的旋转误差：后端投影不能改写原始帧、输入快照或悄悄放宽非法输入；Task 1 测试边界。
3. 旧版本与新增尾帧：优化完成后到提交前增长帧数或提交了其他版本；Task 2 测试尾帧及陈旧结果。
4. 异常或迭代上限：不输出非有限/误差增加结果，不把达到上限标作收敛；Task 1 测试诊断和重试。
5. 编译依赖泄漏与持久化：默认构建不得引入 GTSAM；已重开在线索引不能追加；Task 1/3 分别验证。

### Task 1：可选 GTSAM 位姿图

**Consumes:** 原始 `RigidTransform`、`PoseSnapshot`。**Produces:** `livo_atlas::backend` 和设计中的
`PoseGraph` API；`Optimize` 返回 `PoseGraphResult`，不修改图。

- [x] 写失败测试 `OdometryDirectionAndAnchor`：以绕 z 旋转 90° 的首帧和沿其 body x 方向平移、
  再绕 body x 旋转的第二帧建立无环图；检查零误差和恢复原位姿，能区分 `O_i^-1 O_j` 与反方向。
- [x] 写失败测试 `SyntheticLoopReducesResidual`：五帧方形轨迹中，原始末帧沿 x 漂移 0.4 m；
  加入首末帧间单位变换，回环噪声 0.01 rad/0.01 m。断言代价下降、首帧先验保持、
  首末平移残差小于 0.02 m，且输入数据不变。它不是实际 bag 真值。
- [x] 写失败测试覆盖连续 ID、非有限/非法旋转、缺失和重复回环、反向/相邻约束、非正噪声、
  空图和非法迭代上限；失败后用原有效图求解，确认没有部分插入。
- [x] 写失败测试 `ProjectsOnlyBackendRotation`：保留 `1e-4` 校验内的近似矩阵原值，后端临时投影后
  得到有效 SO(3)；越界矩阵拒绝；严格刚体无回环结果的旋转矩阵和位移误差各不超过 `1e-8`。
- [x] 写失败测试覆盖快照版本 0 前缀逐系数不一致、正版本初值、覆盖范围不足、
  优化前缀回退、非有限误差及对非零闭环图使用 `max_iterations=1` 的达到上限标志；有限零误差允许不下降。
  求解器异常或不合法候选不能修改图；不得将误差不增表述为收敛。未对 GTSAM 内部异常做
  专门故障注入；图接口为 const，求解状态均为局部变量，现有失败测试覆盖非有限初始目标。
- [x] 在隔离目录取得并核验官方 4.2.2 标签及提交，针对 Noetic 和 Humble 分别构建到阶段私有前缀，
  使用系统 Eigen、禁用与可移植性冲突的原生 CPU 编译选项，并记录编译器、Eigen、Boost、ABI 和 CMake 缓存。
  不修改 `/usr`、`/opt/ros` 或 vikit；外部依赖缺失时如实记录，不把跳过写成通过。
- [x] 启用 OFF 分支：强制 `CMAKE_DISABLE_FIND_PACKAGE_GTSAM=ON`，确认普通构建、安装和已有头检查通过，
  未导出后端目标，现有节点和库不加载 GTSAM。ON 且找不到 GTSAM 时配置须明确失败。
- [x] 实现接口与求解：先校验原始数据，在临时副本将旋转按设计投影到 SO(3)，以首帧先验、
  相邻里程计和显式闭环建立 GTSAM 4.2.2 `BetweenFactor<Pose3>`，使用 LM；返回携带新尾帧策略的有效前缀和诊断。
- [x] shared/static 和无 OpenMP 运行本任务测试；ON 的安装消费者只通过安装前缀构建、运行，
  验证 GTSAM 的实际传递链接及缺失依赖时的明确失败。完成后提交 `feat: add optional gtsam pose graph`。
