# CBD 子地图 7 不透明度对照

用 CBD 73 号已冻结的高误差射线，从所属块 7 的实际远层贡献中核对 26 个高斯的索引。绑定原始
资产和射线收据。CBD 65 号使用同一所属块、不同邻块，作为旁证视角。两视角均使用已有最终相机。

比较不透明度原值和乘以 0.75。只针对冻结的索引，在内存中将 `sigmoid(logit)` 乘以因子后转回
原参数类型，并验证实际不透明度比例。用原来的位置、尺度、颜色和变换作控制。邻块参数来自同一
已封口模型。评分使用 73 号冻结的 565 个标签、两幅图的全部有效 LiDAR 标签和固定图像掩码。

深度统计使用双方共同覆盖并另记原有覆盖中的丢失数。比较有符号误差、L1、RMSE、平方误差和
alpha 覆盖。RGB PSNR/SSIM 在相同图像分母计算。73 号复用 64 条射线，重算实际权重、参考层与
远层贡献和期望深度变化。65 号用于观察调整是否带来覆盖或画质代价。

渲染时逐元素复现两份原始 RGB/alpha/深度。第二次运行重新校验像素、比例、渲染和统计。原始
结果由既有评分归档提供，新增保存调整侧的浮点样本和紧凑射线数据。总归档不超过 64 MiB，
保留至少 1 GiB 磁盘空间。记录实际收益和代价，以评估是否值得研究训练约束。
