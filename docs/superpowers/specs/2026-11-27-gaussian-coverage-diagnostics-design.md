# 高斯投影密度与空洞诊断

用户同意继续诊断点密度、投影覆盖和空洞的关系。沿用自主实施、当前分支及本地提交授权，
先诊断，不调默认参数或增加增密/裁剪。实现选择：仅看旧 alpha 图不能知道实际种子；
完整重训并保存地图重复占空间。本轮观察两个既有开发查询的实际初始化和最终保留集合，
保存有界参数与浮点渲染，足以独立复算；不复制 bag 或整张高斯地图。

固定 Retail 查询97(owner6，原生选择5/6)及 CBD 查询9(owner0，选择0)，各seed0/1。
Retail 每次训练5号9帧及6号18帧，共27调用540步；CBD每次11调用220步，合计六个子地图训练、
四次诊断、76调用1520步。它们由已有开发结果选出，不能解释为盲测或全场景统计。
每组最多32原始观测，最多两块，查询必须为冻结split中的heldout且query=true。
使用现有原率coverage/replace25% YAML，1000点/观测、10帧窗口、10000点/块、20步/调用不变。

离线观察类继承OnlineGaussianModel，只复制_append收到的真实初始参数；不改变训练/随机数/预渲染。
训练循环沿用既有相机合成和调度，通过真实CUDA对照train_group的参数、训练ID/步数和驱逐行为。
记录全部实际初始中心、最终保留的同批初始参数以及最终参数；初始保留集合与最终origin逐点对齐。
在最终查询相机上对同一保留集合分别渲染初始/最终参数，分别报告single及可用的joint。
alpha>=0.05定义渲染覆盖，四种覆盖迁移完整分割有效图像；不是表面可见性的真值。

对all_initial、retained_initial、retained_trained三种中心集合，在半径0/2/4像素的圆形邻域统计密度。
遵循暴露K的像素中心约定，投影后u+.5/v+.5再floor，允许邻域覆盖来自画幅外的近边界中心；
只用z>1e-6的有限投影。中心邻域不是高斯椭圆足迹，缺邻域中心不等于绝对无高斯支持。
有LiDAR标签的目标像素，按中心z相对该像素参考深度及max(0.05m,2%z)容差计数：
consistent、front、behind；同时有front/behind且无consistent单列mixed，无中心单列none。
所有互斥类别仅划分带参考深度的最终空洞；无深度空洞单列unknown，不能当作遮挡或缺几何。
initial_all与retained_initial差仅为初始中心保留代理，不是假定历史高斯一直继续训练的反事实。

新纯CPU模块gaussian_coverage.py负责投影/统计；diagnose_gaussian_coverage.py负责观察训练、
原生选块/准备、渲染、报告和CLI。既有训练器、算法、ROS、配置默认和编译开关均不修改。
每次输出为新目录，最多64MiB(与YAML预算取小者)，准备临时空间另算且至少保留1GiB。
预先检查raw数组/图像上界；NPZ/PNG带完整摘要，报告临时写入后原子发布，写入前后检查保留量。
保存split、poses、query浮点参考/渲染及有界子地图参数，支持独立重新准备源观测和GPU复渲染。
GPU按序执行，空闲4096MiB、分配器0.4，OMP/BLAS1。失败不能留下成功report。

报告绑定实际seed/query/owner/selection、配置/库/源地图/原生程序/最终位姿、完整训练与损失ID，
复核每调用/逐来源配额和最终保留；独立审计重算初始化、投影密度、互斥统计、全部产物及渲染。
不因结果增加查询或调像素半径；不声称唯一因果、轨迹精度、跨平台泛化或在线P95。
