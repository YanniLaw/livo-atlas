# 有界高斯种子诊断

继续既有路线中的纹理/多视图及优化变化诊断。复用现有离线准备、冻结split/最终位姿与OnlineGaussianModel，
不修改在线训练器、采样规则、默认YAML或ROS路径。当前会话内直接实施和本地提交沿用用户授权。

采用独立离线工具与仅在工具中使用的观测子类，拦截真实预渲染与初始化结果并复制目标点参数。
相较仅分析现有渲染NPZ，它可追踪真实种子；相较在在线训练器增加通用回调，它不扩展运行时接口。
工具只调用原train_candidate/decide，不另写损失、优化器或调度。观测不能额外渲染或消耗随机数。

每次只运行一个完整主子地图并追踪一个训练帧（最多1000个种子、初始及最多10个训练后快照）。
使用真实预渲染mask重建确定性像素ID，校核初始化XYZ对应。记录uniform入选/未入选、额外入选三组；
uniform未入选只是该次初始化的假设点，不是删除了历史高斯。无预渲染时明确unknown。
初始点统计源RGB亮度中心差分梯度，仅邻域image_mask完整时有效；记录历史训练窗口投影落入图像次数、
具有有效稀疏深度的次数、深度一致次数及一致时RGB差。遮挡与缺深度不能当作零纹理贡献。
投影使用原生准备器约定：暴露的K加回0.5像素转角点坐标，范围[0,width)/[0,height)，再floor索引。
深度一致阈值固定max(0.05m,2%参考深度)，只用于诊断，不影响训练。
参数保存means/log_scales/color_logits/opacity_logits，按稳定origin顺序追踪相同点；报告位移、尺度比、
颜色L1变化和opacity变化。目标必须在最终窗口中；禁止将驱逐或空组当作零变化。

配置沿用已有Gaussian YAML；CLI选择原生参考、子地图、训练帧、随机种子与新输出目录。
重新校核split/source/config/preparer，归档配置与NPZ摘要；固定64MiB产物上限及至少1GiB磁盘保留。
单地图不超过32个主观测；不保存整套模型、bag或重复图像。无新增运行时参数或依赖。

研究在首次追踪前冻结选组：按既有seed0、25%方式对照中单块SSIM降幅，选择训练帧至少11个的最大降幅组，
追踪倒数第6个训练帧。Retail组6/帧98，CBD组0/帧6；各跑resample0、resample25、replace25，种子0/1，
合计12次。选择使用了既有heldout成绩，明确是开发诊断，不是新盲测。只使用train观测产生特征和训练。

验收：手算梯度/投影支持/无深度unknown、相机非单位姿、三类像素集合、空组与非法目标；
CUDA对照确认观测不改变原训练调度/参数（容许已说明的CUDA归约误差），验证真实初始化与跨调用点对应。
全套回归后12次顺序追踪，独立从NPZ重算统计与原始输入/训练ID核验，文档记录结果及边界。
这些是相关性及投影支持线索；不证明光度贡献、唯一因果、全场景效果或在线P95。不据此更改默认。
