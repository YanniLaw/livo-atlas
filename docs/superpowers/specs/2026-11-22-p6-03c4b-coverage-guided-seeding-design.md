# P6-03c4b 面向覆盖的高斯种子分配

2026-11-22，基于 `42fefe3`。本阶段用 C4a 的固定留出划分测试一个变量，即同一训练帧的
LiDAR 种子位置。产出均匀采样与覆盖优先采样的配对画质、深度和资源报告。
[C4a 验证](../../p6-03c4a-validation.md)

## 实测依据与选择

使用原 C4a 模型和划分补测，划分 SHA256 为
`0bafdb25a4b27ecb72053ae0c6f4f3d7be5706428b724356ecd7f485607c0c2e`。

| 检查 | 实测 |
| --- | --- |
| 固定 3 cm 种子的近轴投影尺度 | 147,000 个种子的中位数约 2.06 px，低于 1 px 的占 0.37% |
| 单块和双块共同覆盖的 LiDAR 像素 | 264,003 个，深度 L1 为 0.1935 m 和 0.1901 m |
| 双块新增的 LiDAR 像素 | 26,701 个，深度 L1 为 0.3351 m |
| 训练时已有模型可作参考 | 134 帧，其中 30 帧会淘汰窗口中最早的一帧 |
| 参考模型未覆盖的有效训练深度像素 | 每个有参考的帧均至少 500 个。当前 134,000 个种子中，47,922 个落在这类像素上 |
| 一次训练前预渲染耗时 | 本机探针中位数 1.09 ms，P95 1.56 ms，包含按需筛除即将淘汰的高斯及 alpha 拷回 |

第一行的尺度是 `sqrt(fx * fy) * 0.03 / z` 估计的标准差，实际屏幕覆盖还受投影位置、协方差
及光栅化影响。共同像素与新增区域的误差解释了 C4a 汇总深度指标为何需要同时看覆盖和误差。
实测在本机 `validation/P6-03c4b-preflight-20261122`，见 `baseline-diagnostics.json` 和
`training-coverage.json`。探针读取原模型结果并做统计。

本阶段选择重新分配现有种子配额。按深度放大尺度可用于更远的场景，在当前数据里可直接影响的
亚像素种子很少。扩大窗口或总高斯数会同时改变容量和训练历史，适合另立对照。覆盖优先采样有
直接的本机候选统计，且每帧仍可用现有的训练与内存预算。

Gaussian-LIC 使用当前视角的渲染不透明度，从投影的 LiDAR 点中选新区域。SplaTAM 也使用
已建模型的轮廓判断新观察。这里借用覆盖信号，采用固定配额和本工程的 `alpha < 0.05`。
[Gaussian-LIC 论文，§III-C](https://april.zju.edu.cn/wp-content/papercite-data/pdf/lang2025glic.pdf) ·
[SplaTAM 论文，图 2](https://spla-tam.github.io/assets/SplaTAM.pdf)

## 采样规则

每帧候选为 `image_mask & depth_mask`。令 `N = min(1000, 有效候选数)`。保持 3 cm
初始尺度、0.5 初始不透明度和原始颜色。两种策略使用相同的 LiDAR 反投影、10 帧窗口、
每帧 20 步以及相同的优化、淘汰和组边界。

1. `uniform` 沿用 C4a 按行优先顺序的等距索引采样，也是默认策略。
2. `coverage` 在插入新训练帧之前，使用现有模型在这张训练相机上做一次无梯度渲染。如果窗口已满，
   预渲染只看淘汰最早来源帧后会保留的参数。预渲染使用临时张量，`_append` 负责实际淘汰。
3. 从 `alpha < 0.05` 的有效候选中等距取 `min(N // 2, 未覆盖候选数)` 个，预留这部分配额。
   从全部有效候选的剩余集合等距取满其余配额。索引按行优先排序后再反投影，每个像素至多一次。
4. 空模型、候选数不超过上限、没有未覆盖候选、或全部有效候选都未覆盖时沿用均匀采样。
   空模型和候选数不超过上限时跳过预渲染。预渲染失败应在实际插入前报错。

实验入口为 C4a 的离线评估器。模型调用用可选关键字传入策略。探针仅接收送入训练的当前帧，
留出图像、深度和相机在组模型完成后用于评分。每次运行一个 GPU 模型，每块最多 10,000 个高斯。
配对联合渲染沿用当前组与前一组，每次最多 20,000 个高斯。按训练帧记录是否做预渲染、耗时、
有效候选数、未覆盖候选数和预留配额。

## 评分与决策线

相同封口图、最终位姿、划分、训练顺序和二进制运行两次，分别使用 `uniform` 与 `coverage`。
比较 25 个单块和 23 个联合留出查询，主指标取 23 个联合查询的按像素加权 PSNR 和
`alpha >= 0.05` 覆盖率。逐帧列出组起始、组内结果和训练/渲染资源。

通过可选稀疏深度记录保存同一批 LiDAR 像素的行优先索引、真实 z、预测 z 和覆盖标志。每个文件
以相对路径和 SHA256 绑定报告。深度比较验证两个运行的划分、实际训练 ID、相机、尺寸、像素索引
及真实 z，分别报告共同覆盖的两种 L1、候选新增和丢失的数量及可用的一侧误差。空集合用 `null`。

实现验收以完成真实配对、可复算度量和完整监督来源为准。线上试验的建议筛选线要求联合 PSNR 至少
增加 0.20 dB，覆盖率至少增加 0.50 个百分点，共同 LiDAR 像素上的 L1 增量
不超过 0.02 m。资源用于评估后续在线接入的代价。一次配额对照形成结论，阈值调整属于另一次实验。
