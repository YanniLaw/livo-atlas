# 高斯均值正学习率减半试验

用户已同意继续上一轮建议，沿用当前分支自主实施及本地提交授权。研究 replace25% 下
均值学习率由 0.0005 降为 0.00025 的总效应，其余参数、观测、预算和最终位姿不变。
0.00025 是本轮预先选定的减半值，不按试验结果继续搜索，也不自动修改在线默认。

方案选择：全部重训八次最直接，但重复占用磁盘；复用已审计的四份原学习率基线，只新增
Retail/CBD 各 seed0/1 共四次训练，能节省约一半产物。本轮选择后者，前提是逐文件核对
训练工具源、库版本、原生程序、输入/拆分/最终位姿/选块/配置。训练源不一致则不可复用。
多档学习率搜索暂不做，避免扩大预算及事后挑选。另复用四份 means=0 归档仅作趋势参照。

沿用 Retail172帧/150train/3000步，CBD97帧/85train/1700步，每调用20步，窗口10，
每观测1000点、每子地图10000点。GPU依次运行，最小空闲4096MiB、分配器比例0.4、
OMP/BLAS1线程；启动需8GiB空闲，始终保留至少1GiB。不复制bag/完整模型或复用档案。
同场景原率/半率/零率各两次的六次交集重算深度；该交集与上一轮含冻结尺度的交集不同。
无共同像素返回null，不能写零；表格同时给出交集/参考数、覆盖和两次配对方向。

比较器增加只读 `compare(..., reduced_learning_rate=None)` 和
`--reduced-learning-rate {means,log_scales}`，仅允许指定一项由正数变为更小的正数。
冻结模式继续只允许正数到零；四种显式干预模式互斥。其余原始YAML及有效配置按类型一致，
不得隐藏锚点别处变化、键类型或无关字段默认拼写变化；可省略指定学习率的原默认值。
报告沿用 `comparison_scope=learning_rates.<name>` 和两端数值，图片标明实际学习率。
训练器、模型、ROS、默认配置和编译开关均不修改。

驻留数、PNG/NPZ摘要，重算浮点指标与六次共同深度，并验证四份新比较报告及全部诊断图。
受控配置与旧档案的兼容性先用真实CPU归档用例验证；完整Python/CUDA回归后再跑实验。

轨迹精度、跨平台泛化或在线P95。负结果照实记录，结果、复现方法及资源保存到文档。
