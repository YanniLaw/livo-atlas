# 固定预算的高斯采样对照

用户已认可下一步：复用离线训练工具，在上一轮冻结划分上比较 uniform / coverage，
定位覆盖空洞与子地图接缝，并约束共同深度误差。按会话授权直接实施、验证和本地提交。

## 设计选择

重复在线回放会引入异步重建次数差异；重新实现训练器会偏离实际模型。
采用现有 `train_group` / `OnlineGaussianModel`，新增薄的固定预算执行入口。
原有 C4a/C4b 工具及其历史划分保持可用。

输入为上一轮 uniform-1 的已封口快照、关键帧、原生准备器、选块器和 config YAML。
使用快照已有 HoldoutSplit（全局 ID % 8 == 1 留出），每块全部 train 观测按 ID
恰好训练一次，每次 20 步，保留窗口 10、每观测最多 1000 个高斯，Adam 设置来自 YAML。
每个策略从空模型开始。两策略不固定相同种子位置，因为位置选择正是被研究的变量。
固定随机种子并记录软件与参数、完整训练调度、最终高斯数量、参数摘要和资源消耗。

空间选块在训练前通过现有原生 C++ 逻辑，从同一参考快照冻结。
两策略使用相同选块计划，避免模型变化带来的选块差异混入采样效应。
该选择来自参考模型，不表示各自策略训练后会作出同样的在线选择。
训练只读取 train 图像和深度；留出图像只在训练完成后评分。
最终位姿来自同一快照，并非真值；深度指标是稀疏 LiDAR 相机 z 一致性。

每条查询保存 float32 RGB/alpha/z 及参考与掩码，复用既有 PSNR/SSIM/coverage 定义。
对比器核验相同快照、划分、选块计划、训练配置、每步调度与样本摘要，重算指标；
深度只在两策略共同覆盖的同一像素集合比较，单块和联合渲染分开。
输出最差视角图：参考、渲染、颜色误差、覆盖空洞、稀疏深度误差和联合相对单块变化。
接缝分析是子地图交接视角的诊断，不能把所有误差归为已证明的几何接缝。

## 边界与验收

- 不改变 SLAM/在线 worker 行为、默认 uniform、高斯容量、增密或定位反馈。
- 仅改 livo-atlas；按用户要求在当前 framework_completion 开发分支完成。
- 配置复用 config/gaussian.yaml；实验随机种子是离线工具参数。
- 输入必须验证，输出必须为新目录；失败不得留下成功报告。
- 输出保守预算检查和至少 1 GiB 空闲保留，准备器中间数据按块删除，不复制 bag。
- 使用全部 172 帧，150 个 train、22 个 heldout、21 个预选查询。
- 运行两策略各两次（种子 0/1），每次共 150 次训练、3000 步；比较训练明细必须一致。
- 单场景重复仅描述本地结果，不支持泛化或统计显著性结论。
- 按结果提出一项有依据的后续优化；本轮不提前调整算法。
