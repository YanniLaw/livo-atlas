# CBD 73 号远深度归因

使用两份已封口的 CBD 模型，在同一相机下识别所属子地图 7 与邻块 0 对远深度误差的贡献。
以已有离线诊断中两种半径均支持参考层、近层未重复且参考深度至少 20 m 的 565 个共同联合
像素为初始分母。核对两侧相机、变换、训练谱系、原始标签和邻帧票数。

使用四种联合组合，包括两块均为 flat、只换所属块、只换邻块和两块都换。另复现已有的两种
单块结果。报告各组合在冻结标签上的 alpha 覆盖，联合比较用四份共同覆盖交集。单块用自身的
共同覆盖，也核对与该联合分母的交集。对净平方误差和有符号深度计算单块替换差及组合交互项。

逐射线诊断在两种单块也共同覆盖的像素上冻结。用联合平方误差增量预选 32 个正增量像素，
每 8×8 像素格最多一个。另选 32 个两侧绝对误差至多 0.25 m、深度差至多 0.10 m 的对照，按
参考深度差和图像距离配对。全部六次渲染使用相同坐标。逐高斯跟踪 z、透射率、alpha、权重和
所属子图，并复算归档 alpha 与期望深度。按参考容差 `max(0.20 m, 0.03 × z_ref)` 和子图累计
近层、匹配层与远层贡献，核对各项之和。报告归一化权重变化与层内加权深度变化对输出的作用。

交付固定样本、混合误差、逐射线分层报告和定位图。实验绑定来源、代码、GPU 扩展和结果，用
已有 gsplat 进行定向重渲染。新增数据限于 64 MiB，保留至少 1 GiB 磁盘余量。
