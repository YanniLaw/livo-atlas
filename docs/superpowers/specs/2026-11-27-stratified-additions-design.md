# 仅对补入点分层的设计

固定共同覆盖诊断中，全量分层增加联合覆盖，两场景共同覆盖的弱梯度 SSIM 均下降。
本实验检验二维分层能否改善补点的铺开程度，同时保留更多已有区域的结构。
先用四份冻结反馈归档验证像素选择，再跑 Retail 与 CBD 各两个种子的完整留出前缀。

## 采样规则

用已有 YAML 字段 `gaussian.worker.seed_distribution: stratified_additions` 开启，
要求 `coverage_sampling: replace`。启用覆盖策略时，沿用 `flat` 的基底 U 和移除顺序。
设 H 为当前预渲染中有效 LiDAR 深度候选的空洞，N 为基底的点数，计算：

```
q = min(floor(N * ratio), |U \ H|, |H \ U|)
留下 U 中未被等间隔移除的点
从 H \ U 中按已有二维分层函数选 q 个补点
合并为按像素 ID 排序的 N 个唯一有效点
```

同帧、同掩码下，基底、移除 ID 和 q 与 flat 的 replace 完全一致。
还未产生覆盖反馈、没有可替换点、比例为 0 或显式使用 uniform 时直接保留 flat 基底。
使用现有的 flat、stratified、resample 默认路径及报告字段。比较器在原有单变量开关下接纳
flat→stratified_additions，报告策略必须为 coverage，双方配置必须为 replace。

## 验证口径

先用旧四次捕获重建 76 批冻结掩码，从独立列表采样器得到期望像素。
核对原 flat/全量分层结果、移除 ID、唯一性、数量和合法候选。复用投影计数检查留出最终
空洞的 r=4 邻域种子支持，并报告没有覆盖替换的批次。固定反馈结果用于检查选点机制。

实际留出前缀训练从空模型开始，继承原冻结 split、参考相机/位姿、空间选块、训练窗、
学习率、20 步调度、alpha 阈值和每帧上限 1000，使用 replace/25%。
训练的反馈掩码会随模型变化，按每帧当前掩码计算 q。Retail 150 次调用、CBD 85 次调用，
各 seed 0、1，共 4 次新增运行、470 次调用、9400 步。
复用两场景、两种子的 flat-coverage 和 stratified-coverage 八份归档。

各场景每视角、每模式用六份结果的交集作为共同覆盖，沿用参考梯度阈值 .02 和完整 11×11
SSIM 窗口。另报告全图覆盖率、相对同种子 flat-coverage 的新增/丢失像素、共同深度 L1/RMSE。
Noetic 回放的进入条件是联合覆盖相对于 flat-coverage 增长，且共同区域弱梯度 SSIM
高于全量分层，两个场景的两个种子方向一致。列出丢失覆盖与深度代价，单块结果用于观察局部退化。

新实验写入单独验证目录，复用原有模型与样本，输出上限 2 GiB，磁盘预留 1 GiB，
GPU 使用原归档的 4096 MiB 空闲前置门槛与 0.4 分配器比例。训练顺序执行。
所有实验、测试和提交在现有工作区开发分支上进行。原实验的源码字节证明由其对应 Git 提交核对。
