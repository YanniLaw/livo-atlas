# 仅补入点分层的 Noetic 整包对照

用原始 Retail_Street.bag 的完整 135.47 秒输入，验证两种覆盖采样在真实在线调度下的
处理延迟、封口与留出质量。状态从空模型开始，每轮新进程、独立输出和私有 socket。
两边用同一已验证 Noetic 构建、当前 Python worker、冻结 Retail split、相同的相机和空间选块。
以 1 倍速播 136 秒，图像队列 32，前端 2、后端 4，CPU 2/4/6/8/10/12，
worker OMP/BLAS 1。开启在线子地图、回环、轨迹、高斯持久化、空间联合渲染、在线留出和 Finalize。
worker YAML 除 `seed_distribution` 的 flat / stratified_additions 外一致，均为 coverage/replace/0.25。

每轮记录 IMU/LiDAR/图像计数、LIO/VIO 更新、线程预算、轨迹与位姿、回环接纳序列、
Gaussian 队列峰值、成功/合并/过期计数、GPU 内存、节点和 worker RSS。
P95 分别汇总全前端、LIO、VIO 和 worker 内部训练调用。采样范围与历史整包参考相同，
区分在线执行总量和单次训练耗时，记录退出和修复耗时。完成整包的候选与基准按
固定输入与源资产复查，保留不同运行的真实训练调度与反馈。

首对按 flat→stratified_additions。若任一四项 P95 的绝对差小于等于历史整包
同策略两次运行的最大绝对差，则执行一次反序配对。该比较带用于决定重复次数。
本地保留同样的采样窗口与最终评分，不将该带解释为显著性门槛。试验按配对报告，
若出现相反方向或较大热机/负载差异，保留这些实测上下文。

每个成功运行封口后重新评分，使用统一的 21 个独立查询，预计 19 个联合视角。
对齐参考图像、相机位姿与选块，验证浮点样本和收据，报告全图覆盖、周转及共同区域度量。
固定共同区域对本次全部成功运行在各视角、各模式分别取 alpha>=.05 交集，
用参考梯度 .02 与 11×11 完整 SSIM 窗口，深度仅用交集内有效标签，分别累计 L1/RMSE。
验证原有在线留出不参加训练。比较报告区分定性的在线过程观测与统一最终模型评分。

首对预计约 3.2 GiB。首对连同公共归档最多 4 GiB，执行反序后总量最多 7.5 GiB，
输入与参考只读，保留至少 1 GiB 磁盘余量。GPU 顺序使用，原空闲显存门槛 4096 MiB。
仅在现工作区归档、记录与本地提交。
