# 离线多帧深度支持评分

在既有最终快照留出评分之后增加 CPU 入口。它接受封口地图、关键帧和对应浮点评分，计算每个
视角的多帧支持与深度指标。多个输入共用各模式的覆盖交集，显式配对给出变化量。单份输入也可
使用该入口。配对和排除视角由调用时指定，结果记录完整查询、来源和分母。

复用既有封口、冻结 split、来源和评分样本验证。比较前核对同一物化位姿、相机和选块。按工程
归档的二进制 PCD 重建本帧相机深度，并要求与浮点标签逐元素一致。使用现有 `id±1/±2` 邻帧、
2/4 px 半径、至少两帧和 `max(0.20 m, 0.03 × z_ref)` 容差。逐视角和像素汇总各组的有符号误差、
L1、RMSE、净平方误差和正负变化分量。没有标签的组明确保留零计数和空指标。

入口在验证归档后写一个有界 JSON 文件。原始文件和已存在输出保持只读，失败无成功报告。直接
复用现有快照评分接口，避免将标签诊断引入在线 worker 和训练。比较报告是已保存浮点结果的重算，
用户提供的运行标签只用于记录配对。

实际验收以 Retail 四份、CBD 两份归档复现上一阶段 31 个视角和 58 个共享掩码。随后核对 Retail
的 1 号和 CBD 的 73、57 号在主观察组仍增加的误差。使用相同像素比较深度变化方向、距离区间和
两种半径的重复支持，量化热点的贡献并保存少量对照图。诊断以当前已训练资产为输入。
