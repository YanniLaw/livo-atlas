# P0 自动验证方案

用户已授权 P0-03～P0-08 自动实施与验收。此方案在基线运行前固定，结果见后续基线报告。P1 不在本次授权范围内。

## 运行范围

- 输入：已登记 SHA-256 的 Retail_Street.bag。
- 模式：AVIA 默认 LIVO，相机与外参配置保持原值。
- 重复性：同一起点前30秒，0.5倍速，两次独立进程运行。必要时再运行完整135.47秒序列确认覆盖；完整序列不替代短序列重复性。
- use_sim_time=false，不发布 /clock，明确当前 ROS 输出时间为墙钟而轨迹文件时间为传感器时间。
- 独立 ROS master、ROS 日志和结果目录，不启动 RViz；原始 bag 已含 raw 图像，直接启动映射节点，不启动 republish。此差异只隔离可视化和冗余转发，参数来源与主节点保持一致。
- 只覆盖验证所需输出开关：开启独立名称的 evo 轨迹，关闭 PCD/图像/COLMAP 保存。保存末次发布点云快照，不能称其为全局地图。
- 备份并恢复源码内硬编码日志，保存本次副本。仅关闭本次启动的进程。

## 验收口径

P0-03：回放退出正常，映射节点在回放期间存活，有有限值轨迹、点云和图像输出，正常关闭；参数、日志、时间和内存记录齐全。初始化与末端待同步造成的未输出帧必须解释，不能把输入输出计数差直接叫掉帧。

P0-04：同一设置下两次轨迹时间戳集合相同，无重复/回退/非有限值；不做坐标对齐，比较共同时间戳的姿态。预设工程重复性门限：最大位置差≤0.02米，最大旋转差≤0.1度。若失败，保留失败结果并分析，不事后默改标准。

资源作为基线而非实时性认证：比较同口径RSS峰值和算法已有日志的耗时；暂定后续重构资源回归警戒值为峰值RSS增加20%、平均耗时增加30%、P95增加50%。系统调度抖动需要记录，不能将一次超限直接归因于算法。此处没有真值ATE/RPE准确率门限。

P0-05：核对外参实际方向、两条变换路径和往返误差，有效内参尺寸与主光轴投影；使用配置舍入精度下1e-4米误差门限。验收的是代码与配置语义一致性，真实标定精度未验证。

P0-06：读取实际相邻观测，追踪header、配置偏移、点内偏移和LIO/VIO更新时间；区分原始点offset与预处理校正后的offset。确认每个偏移在正常链路中的应用位置；发现的旧行为明确列入后续修正，不静默改变。

P0-07：列出运行入口、参数命名空间、核心话题/TF/文件语义、RViz依赖和已知迁移风险；动态结果与静态代码证据分别标注。

P0-08：汇总以上证据并确认P1仅以已验证LIVO范围作为首批回归基线；未验证模式、物理标定、真值精度、闭环和长期运行明确排除。没有证据的能力不标通过。
