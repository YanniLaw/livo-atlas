# 高斯种子纹理与优化轨迹诊断

针对[Retail定额替换](gaussian-seed-replacement.md)和[CBD第二场景](cbd-building-sampling.md)中的画质/深度代价，
新增独立离线工具`tools/3dgs_probe/diagnose_gaussian_seeds.py`。它复用原训练器并复制观测，
不改变在线模型、采样规则、ROS接口或默认配置。本轮未新增选择约束。

## 协议与解释范围

先按既有seed0、25%方式对照中单块SSIM降幅，在训练帧至少11个的子地图中选择最大降幅者。
Retail选子地图6（代表留出查询89），CBD选子地图0（查询1）。追踪各组倒数第6个训练帧：98与6。
选组使用了既有留出成绩，因此是开发诊断，不能视为新的盲测或总体效果估计。

各组分别运行resample0%、resample25%、replace25%，随机种子0/1，共12次。每次从空模型完整重放所选组：
Retail18次训练/360步，CBD11次/220步。相同最终位姿、相机与训练观测；window10、每次20步不变。
追踪1000个当前帧种子，保存初始化、当前20步后及后续5次训练后的7个参数快照。
每次后续训练都可能更新这批点，总计观察初始化后120步；追踪帧最终仍在窗口中。

像素分三组：uniform候选中实际入选、uniform候选中未入选，以及额外入选的非uniform像素。
未入选uniform只是本次初始化的假设候选，不是删除了历史地图高斯。真实预渲染mask与实际初始化XYZ对应校核；
0%不额外预渲染，覆盖标签明确unknown。额外CPU观测不增加渲染或随机调用。

源纹理指标为[0,1]RGB加权亮度的中心差分梯度幅值，边界用单边差分，邻域image_mask不完整时不统计。
历史支持只投影到插入后仍保留的历史train相机。按原生准备器的像素约定，对暴露K的投影加0.5，
在[0,width)/[0,height)内取floor索引，避免旋转往返误差丢失边缘或半像素归属不同。
深度一致阈值为max(0.05m,2%参考深度)。
缺少稀疏LiDAR标签时为未观测，不算不一致；深度一致的投影另记录RGB L1差。
这些指标衡量几何/光度一致性的线索，不是实际渲染贡献、可替代性或纹理冗余证明。

resample的25%是空洞优先预留数上限，随后重新均匀抽取剩余位置，所以实际改动可远超25%。
replace25%本轮每次只替换250个候选，保留750个原位置；这两个参数口径不能当作等量位置改动。

下面列seed0的replace25%特征，深度一致次数仅以有参考深度的投影为检查集合：

| 场景/候选 | 梯度均值 | 可见图像投影次数 | 有深度检查次数 | 深度一致次数 | 一致时RGB L1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Retail / 略过的uniform | 0.029890 | 1336 | 56 | 54 | 0.027766 |
| Retail / 新增 | 0.026615 | 724 | 28 | 26 | 0.031875 |

| CBD / 新增 | 0.023478 | 460 | 14 | 8 | 0.008333 |

每组均为250个候选；有效梯度邻域数依次为250/250/250/249。
第二次重复Retail略过/新增梯度为0.032362/0.027095。
第二次重复CBD略过/新增梯度为0.024624/0.018639。
Retail两次都是略过点梯度较高；CBD第一次略低、第二次较高，差异方向没有在全部重复中稳定复现。
alpha已覆盖不能作为低纹理的充分证据，但本轮也不足以支持稳定的梯度保护规则。
但新加入点的深度支持检查很少，且候选位置、表面和可见性不同；不能据此声称梯度选择一定改善画质。

## 保留点仍会继续变化

下表只看各方式中入选的uniform候选，数值为两次描述性均值。三个方式的候选群体不同；
尺度比是三个物理尺度轴的比值均值，不是屏幕覆盖面积比；颜色变化为sigmoid后RGB的平均L1差。

| 场景/方式 | 位移均值(mm) | 物理尺度比 | RGB L1变化 | opacity变化 |
| --- | ---: | ---: | ---: | ---: |
| Retail / resample0% | 32.30 | 1.1221 | 0.1063 | +0.1378 |
| Retail / resample25% | 31.88 | 1.1217 | 0.1120 | +0.1373 |
| Retail / replace25% | 31.98 | 1.1259 | 0.1114 | +0.1409 |
| CBD / resample0% | 28.80 | 1.0996 | 0.0727 | +0.1034 |
| CBD / resample25% | 30.42 | 1.1164 | 0.0889 | +0.1271 |
| CBD / replace25% | 29.31 | 1.1081 | 0.0796 | +0.1138 |

为了减小群体差异，另取同一重复中三方式共同入选的uniform像素。Retail两次只有53/61个，
CBD为64/56个；分别计算相同点的初始化后位移：

| 场景/重复 | 共同点数 | resample0%(mm) | resample25%(mm) | replace25%(mm) |
| --- | ---: | ---: | ---: | ---: |
| Retail / 0 | 53 | 25.37 | 32.29 | 29.96 |
| Retail / 1 | 61 | 30.34 | 30.12 | 29.20 |
| CBD / 0 | 64 | 29.40 | 32.47 | 30.89 |
| CBD / 1 | 56 | 26.62 | 27.10 | 26.28 |

三种方式下点都会移动。共同点样本很小，差异方向也不是两个场景一致：
不能将SSIM下降简单归因为replace使保留点移动更多。初始化位置保留本来就不约束后续均值、尺度、颜色和opacity。
本轮也没有测出这些变化各自对渲染质量的独立因果贡献。

## 验证与复现

完整Python/CUDA382项通过、无跳过；新增测试使用手算的非单位相机、梯度和参数变化，验证缺深度unknown、
空组、越界/重复像素、驱逐/留出目标拒绝、真实初始化对应，以及原模型与观测模型的训练顺序/参数一致性。
审查补齐旋转相机全部15个边缘像素、半像素归属、报告写入中断、空间在训练后减少、外借验证帧预算、
无关子地图仅有heldout时的回归；新增诊断模块10项通过。成功报告完整写入临时文件后原子发布，
写入前后复核磁盘保留量。只对所选组施加训练/32帧约束，仍验证完整参考快照。
CUDA中小规模参数对照容差为绝对2e-5；不将它解释为任意平台的大规模逐位确定性保证。
审查修复后十二次真实追踪已全部重跑，各完成预定训练和7个快照；独立工具重新准备原生源观测，核对像素/XYZ、梯度、投影支持、
训练/损失ID、参数数组、全部阶段统计及来源/配置/位姿/产物摘要。原训练器、在线模型和默认配置源文件不变。

跨电脑使用同一最终参考和配置，替换绝对路径：

```bash
python tools/3dgs_probe/diagnose_gaussian_seeds.py \
  --map-directory /data/reference/gaussian --keyframes /data/reference/slam/keyframes \
  --prepare-executable /sdk/bin/livo_atlas_prepare_3dgs_views \
  --config /data/replace-25.yaml --submap-id 6 --tracked-id 98 \
  --random-seed 0 --output /data/seed-trace
```

参数从既有Gaussian YAML读取。目标必须是指定组最终10帧窗口中的train观测；输出必须为新目录。
每次最多32个主观测、1000追踪种子、11个快照；产物上限取64MiB与evaluation.max_output_mib的较小者，
低于2MiB拒绝，至少保留1GiB磁盘空间。配置、原始NPZ和report.json写入输出目录，失败不会生成成功报告。
prepass_available=false时，NPZ的uncovered字段只是占位，不能当作已覆盖。

工作区`validation/gaussian-seed-diagnostics-20261127/`保存冻结protocol、代码指纹、12套参数轨迹、
执行记录、audit.json、测试日志及独立源观测复算脚本；连同修复前归档与参数曲线总计约9.3MiB，无重复bag、图像或整套模型。
修复前数据在before-final-review中，本文只使用修复后结果。matched-uniform-trajectories.png
展示共同点120步变化，阴影是两次重复的范围，不是置信区间。
仅诊断两个由既有成绩选出的子地图、各一批点及120步；不能覆盖历史高斯、其他帧或完整场景机制。

## 下一步

已完成[单变量冻结试验](gaussian-optimization-ablation.md)：在同一replace25%预算下，分别从初始化
固定所有高斯均值、固定所有尺度，其他参数继续更新。两场景两次重复的画质、覆盖和共同深度均变差，
不采用完全冻结。该试验包含优化经alpha影响后续采样的反馈，不能解释为固定种子的纯几何贡献。
若继续，先单独验证较小的正均值学习率；梯度保护选点继续作为候选，暂不加入在线默认。
本轮保留观测结论，不主张已经找到唯一原因，也不修改uniform/resample默认配置。
