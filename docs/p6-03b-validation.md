分配限制也不约束整个系统的 GPU 内存。

## 回归与失败路径

- 合成 CUDA 测试验证非单位旋转和平移、OpenCV 像素中心转 gsplat 的半像素偏移、RGB、
  米制深度、有限非零梯度和参数更新；移除主点偏移的变异测试实际失败。
- Python 测试共 **17/17** 通过，包括 SDK 观测往返、输出覆盖拒绝、输入损坏、留出帧隔离、
  确定性采样、反投影、掩码损失、无深度和纯黑白初始化。
- 隐藏 GPU 时，训练器返回非零并写入 `status: failed`，错误为 `CUDA is required`；
  请求 101 步时在创建输出前拒绝。准备工具和全部安装 SDK 动态库的 `ldd` 检查未发现 ROS、
  vikit、CUDA、torch 或缺失库。独立 SDK 的 CTest 实际运行 **60/60**，全部通过。
- 独立审阅发现缺失预编译 gsplat 扩展时上游可能自动多任务即时编译。已增加扩展加载
  前置检查；测试先复现进入渲染路径，再验证修复后直接失败。模拟缺失扩展的真实训练 CLI
  写出失败报告，未触发编译。复现命令也隔离已有 pip 配置，并用继承配置的测试验证。
- `conda-linux-64-explicit.txt` 根据 29 个 conda 元数据记录生成，`micromamba create
  --dry-run` 成功；pip 版本清单在本机已安装环境中 `--dry-run --no-index` 全部满足。
  这两项分别验证清单解析与现有版本一致，尚未在另一台机器完成全新联网安装。
