# 传感器外参对象与启动边界

P1-02.a将现有四个外参数组收拢为核心对象。数学约定沿用[P1-01](core-types.md)，运行数值沿用原配置。

| 旧ROS参数 | 对象字段 | 方向 |
|---|---|---|
| `extrin_calib/extrinsic_R`、`extrinsic_T` | `lidar_to_imu_transform` | LiDAR→IMU |
| `extrin_calib/Rcl`、`Pcl` | `lidar_to_camera_transform` | LiDAR→camera |

`SensorExtrinsics`是普通值对象，两个字段为显式单位初始化的`Pose3d`。ROS适配层把行优先9项旋转和3项平移转换为对象；核心层校验几何，不访问ROS参数。单位初始化仅保证对象可安全构造，不能替代缺失的实际标定。

## 初始化路径

入口先加载并验证外参，成功后交给`LIVMapper`，再用于IMU、体素地图和VIO初始化。四个数组不再在映射对象内部重复读取。旧参数命名和各传感器变换方向保留，配置文件不改动。

错误配置在映射对象构造前报告具体参数名并以状态1返回；因此不会先进入算法日志创建和组件初始化。其他参数的初始化错误处理不属于本子项。

## 校验规则

- 四个键必须存在且能读为数值数组；旋转9项、平移3项。
- 数据必须为有限数值。
- 旋转满足 `||RᵀR-I||_F ≤ 1e-4`，且 `|det(R)-1| ≤ 1e-4`。反射、零矩阵、明显缩放不通过。
- 不对输入旋转做正交化，不重新估计外参，不修改YAML舍入值。
- 失败不改写调用者已有输出对象，错误指明对应配置键。

现有四套YAML的Rcl正交误差约1.23e-6～1.36e-6，门限容纳其数值精度；这只是格式和几何有效性检查，不证明真实标定精度、传感器安装方向或时间同步正确。正确的逆旋转同样可以通过几何检查，因此方向还依赖明确的参数映射与点变换测试。

## 范围

本项只接入外参。相机模型/内参/缩放和其他算法参数随后分别迁移；P1-02父任务仍需后续子项。当前默认回归覆盖本机AVIA LIVO短序列，其他设备配置仅完成静态旋转检查。

实际构建、非法启动检查与bag回放结果见[P1-02.a验收单](acceptance/P1-02a.md)。
