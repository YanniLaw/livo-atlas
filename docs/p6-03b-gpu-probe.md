# P6-03b 离线 3DGS 实验

实验工具位于 `tools/3dgs_probe`，独立于默认构建和 ROS 节点。数据准备程序使用安装后的
`livo_atlas::io`，从已停止写入的关键帧数据集生成临时观测包；该包只用于此实验，并非长期
地图格式。实验环境、训练及复现步骤见本页后续内容。

准备工具要求输出目录不存在，且与数据集目录互不包含。`--source-sha256` 是所选输入文件
SHA-256 清单自身的小写哈希；调用前后均应校验该清单。示例见
[实施计划](superpowers/plans/2026-11-16-p6-03b-gpu-feasibility.md)。
