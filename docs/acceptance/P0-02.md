## 用户本地步骤

终端中执行（不需要启动 ROS master，不会播放 bag）：

```bash
cd /home/yanni/livo-atlas_ws
source /opt/ros/noetic/setup.bash
sha256sum -c validation/P0-02/bag.sha256
sha256sum -c validation/P0-02/config.sha256
P002_RUN_DIR=$(mktemp -d /home/yanni/livo-atlas_ws/validation/P0-02-user-XXXXXX)
echo "$P002_RUN_DIR"
/usr/bin/python3 src/livo-atlas/tools/inspect_bag.py Retail_Street.bag > "$P002_RUN_DIR/inspection.json" 2> "$P002_RUN_DIR/inspection.stderr"
echo "检查退出码: $?"
diff -u validation/P0-02/inspection.json "$P002_RUN_DIR/inspection.json"
cat "$P002_RUN_DIR/inspection.stderr"
```
