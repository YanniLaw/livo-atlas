## 根因与最小修复

本机GCC 9.4 / Eigen 3.3.7 / PCL 1.10环境下，`-march=native`使本包Eigen默认动态对齐从16字节变为32字节，使用带额外头信息的分配/释放实现。系统PCL创建的点云缓冲区使用另一种分配约定，本包析构时错误读取指针前8字节。独立VoxelGrid程序的native版本退出139，通用x86版本完成300次点云生命周期；ASan记录了系统PCL分配和Eigen `handmade_aligned_free` 越界读取的完整栈。

唯一跟踪文件修改为 `CMakeLists.txt`：x86 Release移除 `-march=native`，保留 `-O3 -mtune=native -funroll-loops`，增加原因注释。算法、析构、输入配置和launch未改。Luna max实现，主代理审阅。

未改本地vikit或系统依赖：当前相机API边界使用的Vector2d/Vector3d/Matrix3d大小和对齐在两种配置下相同，未通过该边界交换动态Eigen点云缓冲区。此结论限当前接口，不能推广到任意Eigen类型或其他机器/ARM构建。
