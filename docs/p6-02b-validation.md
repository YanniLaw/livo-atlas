# P6-02b 验证记录

状态：**实施中，尚未完成全部验收**。本文记录可选位姿图、版本化刚体尾帧和几何交付的
实际检查；后续补齐双 ROS、完整数据回放与安装消费结果后再更新状态。

## 环境与依赖

验收基线为官方 GTSAM 4.2.2 标签，对应提交
`35dd70360fb39c81081b8f420a4d72e0b896a96e`；下载归档 SHA256 为
`d4420b7ee16fc51cd9afc1f5171d6a315383fc5b58a6375466e7585d90d36d80`。
依赖安装在本阶段独立前缀，没有修改系统目录或 `vikit`。Noetic 使用 GCC 9.4、系统
Eigen 3.3.7 和 Boost 1.71；GTSAM 与工程均使用 C++17，关闭 `-march=native`，禁用
GTSAM 的 TBB 和 Metis 嵌套消元。Humble 的环境与结果待完成后记录。

GTSAM 4.2.2 默认 LM 停止参数使用相对和绝对误差容差 `1e-5`、目标误差阈值 `0`，
默认 COLAMD 排序；位姿图只显式修改最大迭代次数。默认噪声是实验权重，见
[使用说明](pose-graph.md)。

## 已取得的中间证据

- 独立单元与系统场景覆盖非交换旋转、回环方向、旋转／平移噪声顺序、输入失败不污染图、
  非有限目标、迭代上限、延迟提交和陈旧版本拒绝，以及几何重建、原始位姿和前端状态保持。
  换为 C++17 依赖后，图测试和系统集成测试均通过。
- 普通共享库首次验证：启用位姿图为 37/37 个 CTest 目标通过，关闭为 35/35；两种安装
  消费者均通过。关闭模式的消费者没有加载 GTSAM；启用安装包在禁止查找 GTSAM 时明确报错。
  后续又对两处条件分支做了纯格式整理，需要用最终源码重跑共享模式。
- 普通静态库使用整理后的源码验证：启用位姿图 37/37、关闭 35/35，两个安装消费者均通过；
  启用消费者实际链接到本阶段私有 GTSAM，关闭消费者没有加载它。
- 原位姿 schema 1 仍使用旧公式；schema 2 使用投影后的刚体尾帧公式。旧读者对新的 schema 2
  明确报错；新读者能读取和扩展两个版本。对近似旋转和已有尾帧的旧／新行为均有测试。
- 10,000 帧、其中 5,000 帧为优化前缀的本机微基准，10 次物化平均耗时为旧策略约
  0.660 ms、新策略约 0.913 ms。输入是单位旋转，不是完整节点或长距离数据性能。

无 OpenMP、Noetic／Humble 安装消费及完整 bag 的本阶段结果尚在验证中。
所有本机日志和构建输出位于工作空间外层的 `validation/P6-02b-20261111/`；它们不会随本包
自动迁移，应在换电脑时按需单独复制。构建命令见[使用说明](pose-graph.md)。

## 限制

本阶段没有实际回环检测，任何合成约束都不能用来评估真实闭环精度；普通 ROS 节点不会自动
启用优化。批量图、关键帧和快照内存随规模增长，尚不能推断长距离实时性。仅有约 135 秒的
`Retail_Street.bag` 时，重复回放不能替代更长的真实连续数据。优化误差下降也不证明地图正确。
