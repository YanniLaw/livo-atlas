# VIO 缓存均值修复

日期：2026-10-11。在 P1-01 的完整 bag 回归中，默认模式和限制 OpenMP 为单线程的配对回放都未通过零差异比较。
P0 同一个二进制的完整重复回放也有差异，旧、新数学/状态的 20,000 组直接对照没有发现系数差异。

## 明确的错误

`VIOManager::updateReferencePatch` 的 `ref_mean`、`other_mean` 原来只在 `Feature::mean_` 近零时赋值。
均值已有缓存时，后续 NCC 评分读取未初始化的局部量。它们的取值没有定义，完整回放不能以这种输出作为可靠的精确参考。

修复在声明时读取相应的缓存均值。近零时原有的均值重算和缓存更新仍然执行，NCC 公式、视角评分与参考选择流程保持原样。
这项修复单独提交，数值结果的变化与数学/状态结构迁移分别验证。

## 行为回归

`tests/vio_reference_patch_test.cc` 直接调用真实 VIO 方法，设置一个点和六个观察。
各 patch 的亮度偏移不同，去均值后的像素都为 `(0, 2, 0, -2)`；因此 NCC 为 1，正面观察的视角评分也为 1，最终评分应为 2。
测试不使用 mock，不加载 ROS 参数或启动 ROS graph。

- `UsesCachedPatchMeans`：六个均值预先缓存，评分应为 2。
- `ScoresStayEqualAfterMeansAreCached`：先计算并缓存均值，再次评分仍应为 2。

两个用例在未修复的真实 VIO 库上均失败；修复后均通过。
证据位于工作区 `validation/P1-01-noetic-20261011/vio-reference-tests/red.log` 和 `green.log`。
测试链接 OpenMP 运行库；这个链接设置只用于新增的测试目标。

## 完整回放参考

最初配对参考采用原 P0 数学/状态头加上同样的两处均值初始化，仍有完整回放差异。
后续实际诊断确认了 [粗层采样越界](vio-sampling-bounds-fix.md)；最终参考与候选都同时应用该修复。
最终比较对象为原 P0 数学/状态与本轮核心头，VIO 修复、标定及运行条件相同。
两份独立工作区位于 `validation/P1-01-noetic-20261011/vio_mean_fix/p0_ws`、`p1_ws`。
旧工作区及此前失败结果均保留；配对验收的实际结果见 [P1-01 验证报告](p1-01-validation.md)。
