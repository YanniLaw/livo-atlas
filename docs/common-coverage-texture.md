# 固定共同覆盖的纹理诊断

本轮复用[分层采样研究](stratified-seed-sampling.md)的16份模型评分归档，诊断覆盖与PSNR提高、
SSIM下降的关系。只新增CPU分析；不训练、不渲染、不修改优化器、采样器、默认配置或ROS/C++链路。
输入仍是Retail_Street与CBD_Building两个已反复使用的开发场景，不能替代盲测或轨迹真值评估。

## 比较范围与统计口径

每场景为flat/stratified × uniform/coverage × seed0/1，共8次运行。每个查询、每种模式分别固定：

```text
common = image_mask AND (全部8次运行的alpha >= 0.05)
```

这张掩码对8次结果相同。single与joint独立统计；没有joint的查询不进入joint分母。
全图image区域保留空洞，沿用原评分口径。共同区域比较不等于全图比较，也不是每对各自交集。

梯度只看参考RGB：中心与上下左右的RGB平方差求和，除以6并开方。固定阈值0.02，
低于阈值为weak，否则为strong。中心或四邻居越界/无效为unknown；三类完整分割有效图像。
四邻域差异能识别交替细纹理，不会因中心差分相消而误判为平坦。

image/common均报告all/weak/strong/unknown的RGB L1、MSE、PSNR和SSIM。
SSIM使用原有11×11、sigma1.5、C1=0.01²、C2=0.03²，要求**整个窗口位于选定区域**，
梯度类别只由窗口中心决定。每行同时保存像素数、完整窗口数与误差总和；没有像素或窗口为null并说明原因。
完美RGB的PSNR为null且标记perfect，避免JSON中出现Infinity。

另对同策略、同种子的flat→stratified拆成四类：common_covered、gained、lost、common_holes。
这是每对自己的覆盖周转，不与上面的八次共同区域混淆。四类像素数及RGB绝对/平方误差分别重构全图。

```text
该类MSE变化贡献 = (stratified该类SSE - flat该类SSE) / (3 × 全图有效像素数)
```

负数表示降低全图MSE；正数表示增加误差。贡献可加，dB不可加；SSIM也不按这四类像素分解。
每次运行先跨查询累计充分统计量，再计算指标。配对汇总保留seed0/1，文中两种子均值仅作描述，
不是显著性检验，也不代表对两个场景的泛化。

## 双场景结果

下表是同策略stratified−flat的两种子均值。全图PSNR仍提高，但固定共同区域SSIM多数下降；
不能仅用覆盖增加或PSNR说明纹理结构改善。固定区域内RGB均方误差与SSIM也可以朝不同方向变化。

| Retail/uniform | single | +0.725542 | -0.004981 | -0.029513 | -0.044697 | -0.012120 |
| Retail/uniform | joint | +1.039025 | -0.001507 | -0.015095 | -0.025347 | -0.002654 |
| Retail/coverage | single | +0.415448 | -0.005934 | -0.026005 | -0.035272 | -0.015390 |
| Retail/coverage | joint | +0.592382 | -0.003451 | -0.013436 | -0.021461 | -0.003698 |
| CBD/uniform | single | +0.163908 | -0.007525 | -0.020448 | -0.028638 | -0.001306 |
| CBD/uniform | joint | +0.272017 | -0.009003 | -0.028300 | -0.036907 | +0.002780 |
| CBD/coverage | single | +0.091367 | -0.003162 | -0.000128 | -0.006162 | +0.013975 |
| CBD/coverage | joint | +0.173906 | -0.004750 | -0.007914 | -0.013601 | +0.012624 |

Retail两策略/两模式的共同weak损失大于共同strong损失。CBD的共同weak均下降；
共同strong在coverage的single/joint及uniform的joint提高，说明损失不能简单归结为强边缘细节。
CBD/coverage/single共同all两种子分别为+0.000584和−0.000839，均值接近零，不应描述成稳定改善。
CBD/uniform/single共同区域PSNR约−0.148dB，而全图约+0.164dB，是填洞收益与原区域代价并存的例子。
weak/strong是固定参考梯度分组，不能直接等同于语义表面或人的感知质量。

## 验收与边界

新增16项专项测试覆盖手算四类分解、掩码/梯度边界、二维窗口SSIM、空集/完美值、
旧评分一致性、来源/上游产物/待发布文件变化、输出重叠及资源预算。完整Python/CUDA
审查修正后**454/454通过，无跳过，126.811秒**。原有生产评分、训练、采样器、C++/ROS及配置默认字节未改。

真实16份运行、8组同策略配对、33个查询通过来源检查。独立CPU审计用另一套滑窗/einsum卷积、
参考梯度和四类掩码重算全部明细及汇总，核验47,570个浮点数，最大绝对差1.28057×10⁻⁸，
低于预设1e-5绝对/1e-10相对容差；整数计数、掩码摘要、空值及原因严格一致。
原评分的全图all统计与新增统计逐项精确相同。每份诊断输出约2.5MiB，含图、审计及重验的整个新增验证目录约10MiB。

独立只读审查指出四项重要校验问题，已完成一次失败用例→修复→完整回归：
长哈希扫描后再快速复扫文件身份，并在样本解码前后检查身份；按冻结协议核对选块、软件、
审计状态和跨运行种子数/子图变换；安全输出在来源加载失败时也记录failure.json；
独立审计从协议生成配对身份，另有1项本机审计回归覆盖种子/策略错绑与缺失配对。
`review-protocol.json`保留修正前的冻结协议及修正文件指纹，不覆盖历史来源证据。
加强校验后的入口重查全部16份归档，metrics.json与report.json均与原分析逐字节一致，
证明这些修复未改变评分。复核记录为`review-output-identity.json`；分析函数除样本身份检查外AST相同，
度量源码字节保持原样。

这些结果只解释现有两个场景、固定预算与参考梯度阈值下的离线统计；未新增在线P95、
完整bag链路或轨迹精度对照，也不能把稀疏深度/可见性误差归结为单一采样原因。
共同掩码与样本冻结，发布复查检测长期分析期间变化；不提供对恶意并发写入的文件系统事务隔离。

## 跨电脑复现

需要完整的冻结研究归档、静态覆盖诊断及候选诊断根目录，不能只拷贝PNG。
研究协议中的原生map/keyframes路径必须仍可访问；换电脑可按前述研究流程生成当地的冻结归档，
不在本轮增加路径重映射机制。NumPy等依赖沿用已有Python环境。

```bash
python tools/3dgs_probe/diagnose_texture.py \
  --study-directory /data/stratified-study \
  --coverage-directory /data/coverage-diagnostics \
  --candidate-directory /data/depth-candidates \
  --output /data/common-texture-diagnosis

PYTHONPATH=tools/3dgs_probe:tests/3dgs_probe python -m unittest discover \
  -s tests/3dgs_probe -p 'test_texture*.py'
```

`metrics.json`保存每查询和汇总的区域/梯度充分统计量、共同掩码计数/摘要以及配对四类分解；
`report.json`保存方法、全部来源收据、汇总与指标文件摘要。输出必须使用新目录。
本机协议、独立审计、图和复查脚本在工作区`validation/common-texture-20261127/`，属于可删除的验证产物；
复现前应保留所需上游冻结资产。
