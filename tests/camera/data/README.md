# P3 numerical reference

Generated on 2026-10-24 from rpg_vikit commit
`6c886c8e5d83997806e00294826d528cea3581dd`, using its frozen P2-03
Noetic `libvikit_common.so` (GCC 9.4, OpenCV 4.2, x86_64). The generator
is retained in `validation/P3-noetic-20261024/capture_legacy.cc` outside
the package, together with the exact library, environment and file hashes.
It never calls the replacement implementation.

`legacy_camera.csv`: C rows contain id, model, original width/height, scale,
fx/fy/cx/cy, and four distortion coefficients. P/U rows contain id, three
input coordinates and three output coordinates (unused components are zero).
P projects a 3D point; U unprojects a pixel to a unit bearing. Decimal output
has 17 significant digits. NaN is intentional at the distorted equidistant
optical axis; its near-zero projection branch also intentionally lacks the
principal-point offset. The first distortion coefficient alone controls the
legacy distortion switch, with a strict absolute threshold of 1e-7.

`legacy_undistort.csv` contains pinhole configuration id and the FNV-1a
64-bit hash of all output pixel bytes. Input pixels are generated by
`tests/test_images.h`, at the scaled dimensions and three channels.

`../../image/data/legacy_image.csv`: I/S rows contain operation, ROI flag,
x/y and output. I is float bilinear grayscale interpolation; S is the
legacy 8x8 Shi–Tomasi score. The 128x64 deterministic images have either
contiguous storage or eleven padding pixels per row. Hashing excludes padding.

These fixtures characterize existing behavior. Optical-axis model corrections
and new image pyramids require a separate numerical change.
